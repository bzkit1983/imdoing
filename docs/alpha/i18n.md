# 字串表（i18n）

- 活線：`godot/game`
- 表：`locale/strings.csv`（欄：`key`, `zh_TW`, `en`）
- 執行期：Autoload **`Loc`**（`scripts/loc.gd`）— 啟動時讀 CSV，不依賴編輯器產生的 `.translation`
- 預設語系：`zh_TW`（與 `project.godot` `locale/fallback` 一致）

## 用法

```gdscript
Loc.t("pause.title")
Loc.t("hud.revenue", [rev, stolen])  # 對翻譯字串做 % 格式化
Loc.set_locale("en")                 # Steam／英文包時切換
```

已接上的表面：暫停選單、提早關店、HUD 主標籤／目標列、準備選單分頁標題與主選單列、準備殼層按鈕／提示。

其餘約數百條 CJK 字面值（player log、技能名、SKU 名等）仍可逐步遷入；用收割工具列待辦：

```bash
python3 tools/i18n_harvest.py
```

## 加字串

1. 在 `locale/strings.csv` 加一列 `key,zh_TW,en`（換行寫成 `\n`；含逗號的欄位加雙引號）  
2. 程式改 `Loc.t("your.key")`  
3. 若子集字型缺新字：`python3 tools/fonts/subset_notosans_tc.py`  
4. 可選：`Loc.set_locale("en")` 煙測英文欄  

## 規則

- Key 用穩定英文路徑（`prep.home.open`），不要用中文當 key  
- 玩法資料名（技能／SKU／傢俬 `name`）可暫留資料表；之後可另開 `locale/data.csv`  
- `*.translation` 仍 gitignore；本方案不依賴 Godot CSV Translation 匯入  
- 不要為語系複製 `godot/game`（見 `docs/versioning.md`）
