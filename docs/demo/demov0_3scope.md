# Demo 版設定（與長線設計不同之處）
## 時間
- 補貨時段：遊戲時間 06:00–08:00，**現實 30 秒**，無客人
- 營運時段：遊戲時間 08:00–22:00，**現實 3 分鐘**，客人進店
- 結束後關店結算（顯示營業額、成功收銀人數、生氣離開人數）
- 畫面以環型時計顯示遊戲時間
- （長線設計見 `storeoperationphase.md`：補貨 1 分鐘、營運 5 分鐘）

## 角色能力
- 玩家 STR / AGI / INT = **20**
- 負重上限 16 件（STR 轉換表尚未定案，本 Demo 沿用可玩預設）
- 客人移動速度**獨立計算**，固定相當於 **AGI 10**，不隨玩家能力改變
- （長線／v0.1 預設能力為 10）

## 客人生成
- 營運時段每 **5 秒** 生成 1 名新客人
- 在店人數上限 15（離開中的客人不計入、不擋門）
- （長線設計為每隔 10–15 秒）

## 購物清單
- 隨機 2–8 件（上限規則仍為 15）
- 可重複、僅乾貨＋凍櫃可售貨品
- 頭頂顯示清單與狀態（高對比配色＋描邊）

## 不滿度（本 Demo 可玩預設，設計文件未定表）
- 上限 100
- 找不到貨：+18，思考 3 秒，該件移到清單最後
- 排隊：每秒 +5
- 污物：每秒 +8 並減速
- 達上限則生氣沿走道出大門離開
