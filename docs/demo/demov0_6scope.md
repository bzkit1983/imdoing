# 測試目標
此版本設有兩個不同測試版本分支,在開始遊戲前能選開始進度:
劇本1. 從新開始
劇本2. 由LV5開始
劇本3. 由LV10開始

# 劇本1
# 資金配置
- 起始資金為1000
# 經驗值
- 0
# 玩家角色進度
- 玩家 STR / AGI / INT = 10, LV=1
# 店舖進度
- 初始狀態
# 店員狀態
- 沒有店員
# 貨品狀態
- 沒有任何貨品, 玩家能自行購買
# 店舖物品狀態
- 沒有任何商店物品, 玩家能自行購買
# 店舖規模
- LV1
# 店舖設計圖
- 為空, 等玩家自行設計
# 商店設計配置
- 根據玩家自行設計而配置, 沒預設
- 按玩家設計進行
- 污物：開局隨機 2 處，之後每 12 秒再生成 1 處（同時最多 6），三類等機率，位置避開傢俬與大門
# 營運回合店舖配置
- 按玩家設計進行
- 污物：開局隨機 2 處，之後每 12 秒再生成 1 處（同時最多 6），三類等機率，位置避開傢俬與大門
# 技能設定
全技能已獲得, 能自行裝備
## 客人生成
- 營運時段每 **10 秒** 生成 1 名新客人
- 在店人數上限 10（離開中的客人不計入、不擋門）
- （長線設計為每隔 10–15 秒）

# Demo 版設定（與長線設計不同之處）
## 時間
- 補貨時段：遊戲時間 06:00–08:00，**現實 30 秒**，無客人
- 營運時段：遊戲時間 08:00–22:00，**現實 3 分鐘**，客人進店
- 結束後關店結算（顯示營業額、成功收銀人數、生氣離開人數）
- 畫面以環型時計顯示遊戲時間
- （長線設計見 `storeoperationphase.md`：同樣為補貨 30 秒、營運 3 分鐘）

## 角色能力
- 按不同劇本初始

## 鏡頭
- 預設 Camera2D zoom **1.22**（人物與店內物件略放大；HUD／虛擬鍵維持畫面像素）
- 施放技能短暫再拉近約 12%、奧義約 28%，然後回到 1.22

## 客人購物清單
- 隨機 2–8 件（上限規則仍為 15）
- 可重複、僅乾貨＋凍櫃可售貨品
- 頭頂顯示清單與狀態（高對比配色＋描邊）
