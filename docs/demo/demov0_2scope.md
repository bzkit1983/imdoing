# DEMO V0.2 Scope
# Demo版關卡2（已完成）

- 此檔案包含 Demo v0.2 的實作範圍與**本 Demo 實際採用的數值**
- 工程路徑：`godot/demo_v0_2`
- v0.2 以 v0.1 為基礎，補上店鋪經營回合的**時間流程、客人行為、凍櫃貨品、貨品價格與收銀系統**
- 完整系統設計仍以 `docs/systemdesign/` 為準；下列「Demo 版設定」若與長線設計不同，以本檔為 Demo 準則

# 版本目標
- 直接由店鋪經營回合開始
- 實作營運回合設定（補貨時段 → 營運時段 → 關店結算）
- 實作客人設定（進店、取貨、排隊、不滿、離開）
- 實作貨品價格設定（收銀計入營業額）
- 實作收銀行動指令
- 不實作技能設定
- 不實作角色等級
- 不實作冰櫃類貨品、清潔、打擊、店鋪準備回合、商店資金入帳

# 設定套用（繼承 v0.1）
- 鍵盤操作：WASD 移動、J 行動、K 輕按衝刺／長按奔跑
- 執貨即時、上架長按 Loading Circle（放手重置）
- 攜帶清單 FILO、一箱 4 件、同類連續上架
- 鏡頭俯瞰跟隨玩家
- 污物減速

# 商店配置
- 商店大門（北面）
- 收銀機 1 台（客人在前方排隊，玩家在後方收銀）
- 乾貨補貨點 1 個
- 凍櫃補貨點 2 個
- 乾貨貨架 3 個
- 凍櫃貨架 3 個
- 補貨點各種貨品 99 箱
- 貨架容量 12 件／架
- 污物 2 處

# Demo 版設定（與長線設計不同之處）
## 時間
- 補貨時段：遊戲時間 06:00–08:00，**現實 30 秒**，無客人
- 營運時段：遊戲時間 08:00–22:00，**現實 3 分鐘**，客人進店
- 結束後關店結算（顯示營業額、成功收銀人數、生氣離開人數）
- 畫面以環型時計顯示遊戲時間
- （長線設計見 `storeoperationphase.md`：補貨 1 分鐘、營運 5 分鐘）

## 角色能力
- 玩家 STR / AGI / INT = **20**
- 負重上限 16 件（STR 轉換表尚未定案，本 Demo 沿用可玩預設）
- 客人移動速度**獨立計算**，固定相當於 **AGI 10**，不隨玩家能力改變
- （長線／v0.1 預設能力為 10）

## 客人生成
- 營運時段每 **5 秒** 生成 1 名新客人
- 在店人數上限 8（離開中的客人不計入、不擋門）
- （長線設計為每隔 10–15 秒）

## 購物清單
- 隨機 2–6 件（上限規則仍為 15）
- 可重複、僅乾貨＋凍櫃可售貨品
- 頭頂顯示清單與狀態（高對比配色＋描邊）

## 不滿度（本 Demo 可玩預設，設計文件未定表）
- 上限 100
- 找不到貨：+18，思考 3 秒，該件移到清單最後
- 排隊：每秒 +5
- 污物：每秒 +8 並減速
- 達上限則生氣沿走道出大門離開

# 新增內容（相對 v0.1）
- 營運回合 HUD：時計、時段、營業額、在店客人、商店／角色狀態
- 客人 AI：進店 → 依清單找貨架 → 逗留 1 秒取貨（貨架數量 -1）→ 收銀排隊
- 走道尋路：不穿過貨架／補貨點／收銀機
- 購物客人之間不互撞，避免堵死
- 離開中的客人沿可行路徑出店，不阻擋其他客人
- 收銀：隊伍**最前且已走到收銀機前**才能開始指令
- 收銀指令：長按 J，WASD 輸入隨機方向串；錯則同一串重來；完成後 INT Loading Circle；成功彈出 $ 並加營業額（不即時入商店資金）
- 凍櫃補貨點與貨架、凍櫃三項貨品及售價

# 操作（營運回合鍵盤）
- WASD：移動；收銀指令狀態時改為方向指令且不能移動
- J／Enter：執貨即時；上架／收銀長按
- K：輕按衝刺、長按奔跑
- Q／E 或 1–3：面向補貨點選貨
- L／;／U：本 Demo 不實作技能

# 明確不實作
- 技能、等級、冰櫃、清潔、打擊、客人撞飛、限時以外的準備回合、商店資金結算入帳
