## 1. 總評一句話

Pitch 最強處是**玩法幻想與主題反諷已經對上**：用暴力／必殺技解決店務，卻宣稱要守護「自然經濟的人性之美」——這本身就是可賣的主題張力。最弱處是動機與終局意義空白，以及「賽博龐克反烏托邦」若照字面落美術／UI，會撞上現有 Cozy 母本。

**專業建議：** 敘事走荒誕新香港＋跨維壟斷；呈現仍保 Cozy／卡通誇張——**企業是劇本敵人，不是視覺主題**。

## 2. 世界設定分析與再定錨

### 2.1 現有 pitch 優缺

| 元素 | 評價 |
|------|------|
| 香港式現代／破舊／有序混亂 | 極適合便利店日常＋超能力並存；環境敘事母題清晰 |
| 多元宇宙混亂→超能力／魔法／異種 | 正好餵養第2章破局與後期客人荒誕升級 |
| 財閥壟斷 | 給「為何一直開店」一個可擴張到六主題的系統性敵人 |
| 全盤賽博龐克視覺 | **風險高**：與暖系 UI、港式幽默技能名、動森感衝突 |

### 2.2 推薦世界錨（Version 1.1 概念）

**「便利店才是最後的公共廣場」**——在略顯荒誕的大都會（原型：香港），生活還能靠一間獨立超商維持人情與可負擔物資。財閥不是暗黑霓虹巨廈 alone，而是**把每個宇宙都做成同一間連鎖店的無形之手**。魔法、惡魔、智龍人、鬼魂可以出現，但他們進門還是要找貨、排隊、結帳——荒誕來自「異種也要消費」，不是來自成堆 lore dump。

### 2.3 主角最終目標（填空建議）

現行 canon 無動機。三個誘因候選裡，**器官販賣**情緒強但與 Cozy／卡通誇張調性撕裂，不建議作主軸。推薦合成：

| 層 | 內容 |
|----|------|
| 外層（系統性） | 你這間店是所有維度裡**最後仍獨立的便利店**；一旦被併購，每個宇宙的咽喉都被同一協議掐住 |
| 內層（情感） | 社區／街坊靠你提供可負擔物資；「自然經濟」＝人與人之間還能講價、幫忙、記住誰欠誰一支菸的交換 |
| 行動聲明 | 受夠對面街冒出來的連鎖旗艦後，決定用更「有說服力」的店務手段（必殺技、投擲貨品、衝撞控場）去經營——**手段荒誕，目的仍是守護人性尺度的交換** |

**拯救的是什麼：** 不是公主，而是**「選擇權」**——客人還能走進一間不是財閥演算法決定貨架的店；以及**「店員這個職業的尊嚴」**（STR／AGI／INT 成長＝把被碾壓的勞動重新變成英雄職能）。

### 2.4 反派（避開「荒坂」等版權名）

工作稱（定名可後改）：**「一元超商協議」／OmniShelf／全維便利**。

核心詭計：

1. 不是只開一間對面店，而是**在每個宇宙複製同一套最適貨架、同一套 VIP 流程、同一套併購合約**。
2. 破局後玩家以為逃離了對面街——結果每個主題世界都已有（或即將有）同一連鎖的分身。
3. 終章頭目＝**跨維總部的「最終結帳協議」特殊營運日**（仍是本店頭目日，符合現有頭目設計），而不是另開射擊關。

```text
序章（日常）
  → 第1章（擴店）
  → 對面旗艦登場
  → 第2章破局（多元宇宙）
  → 槽3–8 自選主題
  → 中點：企業也是跨維的
  → 終章：最終結帳協議
  → 後日談／分支結局
```

## 3. Intro 玩法 × 敍事協同

### 3.1 已對齊（勿重造輪子）

店務動詞＝戰鬥動詞已在系統落地：補貨／投擲交付／收銀指令／清潔／抓賊／衝撞，由技能放大成 combo／AOE／時停。

職業幻想不必硬掛「戰士／魔導士／聖騎士」標籤——用 **STR／AGI／INT 配裝**讓玩家自認成「貨架戰士／結帳魔導／安撫聖騎」即可；敘事稱「店主職能覺醒」比傳統職業表更貼題。

### 3.2 Intro 應教會的「故事規則」（非教學文案）

1. **這間店很弱，但還是你的。**（序章：乾貨、評價、第一個尖峰日）
2. **正當經營擋不住對面旗艦。**（第1章末／破局前：對手店登場＝事件）
3. **必殺技不是外掛，是你選擇的「說服力」。**（技能解鎖＝主角道德滑坡／英雄化的同一條線）
4. **客人會越來越不像「人」，但需求仍是消費。**（為後期外星人／吸血鬼／機甲預告）

### 3.3 第一印象節奏（「序」）

| 節拍 | 掛載 | 玩家感覺 |
|------|------|----------|
| 日常入門 | `prologue` | 我懂怎麼開店 |
| 壓力升級 | `chapter_01` | 擴店、麻煩客、對面開始動 |
| 誘因＋破局 | `chapter_02` / `theme_break` | 我受夠了；世界裂開；店可穿越 |

破局章頭目建議敘事包裝：**對面連鎖派來的「併購稽核團／VIP 清場日」**——通關不是殺掉企業，而是用超商店手段活過第一波吞併，意外撕開維度縫。

## 4. 敍事結構對齊現行 slot×theme

經典弧線應對進現有雙層模型（**勿**改回固定世界線性 2→8）：

| 經典節拍 | 掛載位置 | 設計意圖 |
|----------|----------|----------|
| 序／第一印象 | 序＋第1 | 規則＋日常＋社區情感 |
| 事件 | 第1末→第2 | 對面旗艦／併購最後通牒 |
| 劇情發展 | 槽3–8（自選主題） | 障礙變複雜；每主題一種「壟斷已勝／未勝」的世界切片 |
| 中點 | 約清完第3個主題後（slot 深度中段） | 發現財閥也是跨維的；使命從「救街坊」升級為「救交換本身」 |
| 高潮 | `finale` | 最終結帳協議；六主題能力全員回響 |
| 結論 | `afterstory`＋結局旗標 | 選擇後果；回訪世界看改變 |

### 4.1 分支敘事：淺支深終

全線重度分支不適合「每主題一套內容包」的產量。建議：

- **主題內淺支：** 接受／拒絕企業臨時合約、對奧客仁慈或強迫消費、精英店員招募方式——改短對話、客人修飾、小獎勵。
- **終章深支：** 2～4 個結局（例：獨立聯盟成立／成為「較溫柔的壟斷」／店成跨維避難所／你自己變成新協議）。結局讀累積旗標（人性／效率／獨立），不是六條完整平行劇本。

符合「敘述也是回饋」：文字少、時機準、主要回報玩家剛做過的店務行為。

## 5. 主題再想像（可不沿用現草稿名）

現行六主題（歷史／儀式／奇幻／科技／氣候／鏡子）可用，但應用**同一反派透鏡**重寫方向，避免變成無關觀光：

| 工作 theme | 再想像核心 | 企業影子 | 客人荒誕方向 |
|------------|------------|----------|--------------|
| 歷史城下町 | 封建專賣令下的「官許商」 | 特許狀＝古代連鎖 | 武士催促、藩主VIP一次買光米 |
| 儀式／禁忌 | 祭祀經濟 vs 量販褻瀆 | 企業把神器做成SKU | 惡魔要退貨、鬼魂排隊 |
| 奇幻 | 冒險者補給站 | 公會已被企業承包 | 龍人屯蛋白、魔導士不耐煩 |
| 科技／賽博切片 | 演算法貨架已勝的宇宙 | 母公司總部感 | 矽谷VIP、義體小偷 |
| 氣候災難 | 物資即人命 | 災害漲價協議 | 難民潮、囤積怪客 |
| 鏡子 | 規則顛倒的「若你也被併購」 | 你對上自己的連鎖分身 | 行為規則變異 |

若要更大膽替換其中 1～2 席（仍保六席終章閘），可考慮：

- **路邊攤宇宙**（最小經濟單位）
- **兒童動畫宇宙**（純卡通強迫消費反差）
- **死後世界超商**（鬼魂日常）

原則只有一條：**每個主題必須回答「獨立店在這裡對抗壟斷的方式有何不同」**，否則只是換皮關卡。

## 6. 非文字敘事與環境優先（實踐）

| 手法 | 落到本專案 |
|------|------------|
| 環境 | 同一店殼，主題只換窗外天際線、貨色、客人模型、BGM；對面「一元超商」霓虹在破局前永遠亮著，破局後各宇宙以不同皮出現——玩家自己拼出「原來到處都是同一家」 |
| 回饋文案 | 少旁白；多用結算條、評價浮動、企業傳真／併購簡訊、頭目日廣播 |
| 動詞情感化 | 投擲貨品＝「把需要交到人手上」；強迫消費技能＝主題反諷高潮（你是否變成你所恨的？）；安撫／清潔＝人性經濟的柔線 |
| 客人升級 | 前期可辨識人類原型 → 中期職業誇張（忍者小偷、矽谷VIP）→ 後期異種／機甲；行為需求卡通化，與 `story_slot` 麻煩客 LV 階梯一致 |

## 7. 與現有框架的衝突與決策（概念預設）

1. **調性：** 敘事反烏托邦＋手段暴力；**美術／UI 維持 Cozy 荒誕**，不走暗黑 cyber HUD。
2. **動機：** 「最後獨立店＋社區可負擔物資」雙錨；器官債不作為主線（可作後日談黑暗傳聞）。
3. **頭目形態：** 維持「特殊營運日」，企業戰＝極端店務，不另開戰鬥場景。
4. **職業：** 不新增職業系統；用屬性＋技能 loadout 承載戰士／魔導／聖騎幻想。
5. **產量：** 淺分支＋深結局；六主題各一精英店員＝六種「被壟斷世界裡仍選擇站你這邊的人」。

## 9. 關鍵創作洞見

- 遊戲賣的不是「打財閥」，而是**「在荒誕消費社會裡，勞動與服務被重新英雄化」**。
- 必殺技愈強，主題問題愈尖銳：你是在救人，還是在用更高效的暴力完成結帳 KPI？
- 多元宇宙選章的敘事藉口不只是換皮，而是**企業已經贏了五次，你在第六次宇宙種下獨立店**——終章才有「集合大成」的情感重量。

> **對照：** 技能／奧義 id 優先複用 [`growth-skills.md`](../systemdesign/story/growth-skills.md) 建議歸屬，允許再想像

## V1-A. 七元素設計原則

每個主題包先寫**一句幻想句**，七元素全部服務這句——否則變成換皮關卡。

| 元素 | 設計問題（必答） | 常見失敗 |
|------|------------------|----------|
| 技能 | 本主題教會／放大哪一個店務動詞？跨主題帶走後仍有用嗎？ | 純視覺皮膚、無新決策 |
| 新貨／貨種 | 引入哪種新壓力（時限／易碎／禁忌／條件價）？ | 只換貼圖同價 |
| 商店物品 | 改了動線、容量還是自動化？玩家佈局有新題嗎？ | 裝飾家具無玩法 |
| 精英店員 | 誰是這世界的「臉」？專長覆蓋主題最痛的崗位？ | 通用加強版雇員 |
| 奧義 | 頭目日幻想一句話＝一顆店務核彈？ | 與主動技能無差別的大數字 |
| 小遊戲 | Prep／支線教主題幻想或發外觀／副精英？時長可重玩？ | 與店務無關的休閒島 |
| 主角外觀 | 跨宇宙一眼可辨的身份徽章？ | 與主題敘事無關的時裝 |

**節奏建議：** 每主題學會約 2–4 主動／被動（事件發）＋ 1 奧義（頭目首次）；貨束 2–4 SKU；店物 1–2 關鍵件＋裝飾；精英 1 主導；小遊戲 1 套（可發非劇情精英或外觀）；外觀 1 主 skin（可加 tint）。

**跨主題可帶：** 技能／貨開發權／奧義／外觀／精英＝穿越敘事；店物若綁世界規則可「概念保留、回訪才全效」。

## V1-B. 破局 `theme_break`

**幻想句：** 第一間對面旗艦逼你撕開維度縫。

| 元素 | 概念方向 |
|------|----------|
| 技能 | 清潔／禮貌衝撞／抓賊線（對齊：`sweeping_monk` `polite_dash` `wave_step` `thief_sniper`）——「併購稽核團」進店搗亂時的生存技 |
| 新貨 | 傳統日用延伸（傘、即食粥、報紙立架感乾貨）；毛利中段；暗示「社區剛需」 |
| 商店物品 | **對手偵察窗／對街螢幕**：店內可見對面旗艦排隊長度（資訊傢俬）；小型第二清潔站 |
| 精英店員 | **阿蘭（暫）**：原對面連鎖離職員工，懂企業話術；專長安撫＋識破「假促銷客」 |

## V1-I. 元素橫切檢查表（設計審用）

每包定稿前自問：

1. **一句幻想**是否仍成立？七格有無「觀光件」？
2. **帶走價值**：技能／奧義／精英回其他宇宙是否仍有獨特用途？
3. **新壓力**：貨或店物是否製造新失敗方式（不只數值＋10%）？
4. **反諷**：有沒有一件元素讓玩家覺得「我有點像企業」？
5. **小遊戲**：是否教學主題動詞或發身份獎勵，而非無關休閒？
6. **外觀**：跨主題並存時，玩家是否仍認得「我是獨立店主」？
