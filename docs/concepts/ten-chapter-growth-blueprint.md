## 2. 成長哲學

- **玩法骨架不變**：準備 → 營運 → 結算；變的是主題外皮、貨品束、麻煩客人行為、章末壓力。
- **主線求節奏，後日談求長尾**：終章結束約 **LV60**；**LV61–99** 留給自由遊玩／隱藏／挑戰。
- **壓力靠行為變體，不只靠數值**：每章至少一類新麻煩行為；章末為大型特定玩法營運回合。
- **技能按事件解鎖**：用現有主動／被動的「角色」分桶登場；COST3 偏中後段。
- **奧義約一章一個**：常規約 10 + 隱藏 2–4，總量約 **12–14**（落在 10–15）。

## 4. EXP 曲線與驗算

### 4.1 錨點

| 錨點 | 累計 XP（從 LV1） | 佔滿級比例 |
|------|-------------------|------------|
| LV60（終章結束） | **130,250** | ~42% |
| LV99 | **311,600** | 100% |
| 後日談（60→99） | **181,350** | ~58% 長尾 |

設計意圖：主線節奏緊湊；滿級不靠主線硬磨，靠後日談挑戰／輪換日。

### 4.2 升一級所需 XP（概念公式）

到達目標等級 `L` 所需的「單級門檻」：

| 區段 | 到達 LV | 單級門檻（約） |
|------|---------|----------------|
| 教學短步 | 2–20 | 200 → 1,300（線性） |
| 中盤 | 21–40 | 1,500 → 2,800 |
| 主線後段 | 41–60 | 2,800 → 4,500 |
| 後日談前 | 61–80 | 3,800 → 4,650 |
| 後日談長尾 | 81–99 | 4,695 → 5,500 |

區段累計：

| 區段 | 累計 XP |
|------|---------|
| LV2–20 | 14,250 |
| LV21–40 | 43,000 |
| LV41–60 | 73,000 |
| LV61–80 | 84,500 |
| LV81–99 | 96,850 |

精確公式（概念，非整數表全列）：

```
L∈[2,20]:  round(200 + (L-2)×(1100/18))
L∈[21,40]: round(1500 + (L-21)×(1300/19))
L∈[41,60]: round(2800 + (L-41)×(1700/19))
L∈[61,99]: round(3800 + (L-61)×(1700/38))
```

## 6. 貨品成本／賣價／收入假設

### 6.1 原則

- 每章引入 **2–4 個新 SKU 主題束**（抽象品類，**不綁**現行 `can`／`snack` 等 id）。
- 毛利：前段高容錯 → 中段低週轉高成本 → 後段高賣價但損耗／BOSS 波動大。
- 收入在關店入帳；損耗／失竊不入營收（與現行生態一致的概念）。

## 9. 後日談（LV61–99）與滿級收束

- **內容**：全主題輪換店、隱藏奧義、麻煩圖鑑、自訂規則挑戰；**無主線擋進度**。
- **成長**：XP 曲線略緩於主線末單級峰值後再爬升；鼓勵挑戰日高 XP，而非無限普通日。
- **商規模**：停在 S6；成長轉為外觀／圖鑑／挑戰稱號（概念），避免無限擴店。
- **滿級 LV99**：約再需 18 萬 XP；以挑戰為主時約 1.5–2.5 個月遊戲日量級（視日均）。

## 10. 整合路線說明

單軸時間：序章 → … → 終章 → 後日談。並行疊加六條軌：

1. **LV**：1→60 主線收束；61→99 長尾  
2. **商規模**：S1→S6 約每 1–2 章一檔  
3. **經濟**：毛利帶下降、日預算上升、BOSS 倍率上升  
4. **技能**：基礎 → 移動 → 清潔治安 → 物流 → 收銀高階 → 炮台 → 人力 → 場域 → COST3  
5. **奧義**：約一章一個；隱藏收在後日談  
6. **壓力**：每章 +1 行為類型；章末 BOSS；終章多階段；後日談輪換  

視覺化見 Canvas 分圖與整合圖。
