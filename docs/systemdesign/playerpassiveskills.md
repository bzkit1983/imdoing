#被動技能設定
- 此檔案包含被動技能設定
- 設計以中文為主；玩家可見名稱／簡述的多語見 `locale/data.csv`（`skill.<id>.*`）。新增或改名時遵循 [`AGENTS.md`](../../AGENTS.md) → [`agents/skills/i18n-content/SKILL.md`](../../agents/skills/i18n-content/SKILL.md)。

#被動技能
##名稱: 負重增加
技能類別: 被動技能
施放對象: 自身
說明: 玩家角色貨品攜帶量在營運回合開始時增加。直接加負重（**件**），不改 STR，可超過 STR 50＝44 件。多重影分身不複製這招（補貨仍一次取 `min(架空位, 倉庫件數)`）。等量：舊 +5／15／20 箱 → +20／60／80 件。
技能插槽: 1格
效果:
- LV1:負重 +20 件
- LV2:負重 +60 件
- LV3:負重 +80 件

#被動技能
##名稱: 收銀速度增加
技能類別: 被動技能
施放對象: 自身
說明: **Perfect** 親收成功後，下一客開場從指令串**切走**頭 N 格（頭上只顯示餘下要輸入的箭；切走的不算錯誤）。打完餘下且無錯仍可再 Perfect（連鎖繼續）。**一旦撳錯**：即還原完整指令串由頭打，本客不算 Perfect，連鎖中斷（之後客人回復滿額指令，直至再次 Perfect）。非 Perfect 入帳不給預填；未消耗預填最多一層。**不改 INT**、無 Circle。影分身無箭頭，**不分給分身**。見 `cashiersystem.md`。
技能插槽: 1格
程式 id: `checkout_speed`
效果:
- LV1:下一客略過頭 **1** 格（只顯示餘下）
- LV2:下一客略過頭 **1** 格（只顯示餘下）
- LV3:下一客略過頭 **2** 格（只顯示餘下）
準備頁可選等級；沒選預設 LV3。

#被動技能

程式 id: `quick_swallow`
技能類別: 被動技能
施放對象: 自身

#被動技能

技能類別: 被動技能
施放對象: 自身
說明: 玩家角色裝備時，衝刺撞上一般客人仍會 Screen KO／掉貨／重新購物（**清單不變**、不重抽），但**不滿度不增加**（基值 +50 → +0）。衝刺撞多重影分身本來就沒有不滿，這招不改變那一段（見 `shadowclone.md`）。這招不分給分身。

#被動技能
##名稱: 凌波微步
技能類別: 被動技能
施放對象: 自身
說明: 裝備時完整豁免污物負面效果（不只移速）。
技能插槽: 2格（COST 2，仍只佔一個具名插槽）
效果:
- LV1:
  - 污物上不減速（忽略 ×0.5）
  - 在污物上 **dash** 時按當前路徑高速繞過污物（有特效）
  - 垃圾上行走**不扣氣**
  - 水漬上奔跑／衝刺**不會滑倒**；若在水漬中開始 dash，則以衝刺高速離開污物
  - 嘔吐物上行走**不禁技能**、**不減** STR／AGI／INT 效果
擁擠「唔該借借」減速**不受**此被動豁免（見 `playermovement.md`）。施放多重影分身時若已裝備這招，分身走污物的豁免與玩家相同（見 `shadowclone.md`）。主動技 **掃地僧** 是時限內「清污＋豁免」（見 `playeractiveskills.md`）；本被動只豁免、不清除污物。
