## 1. 目標與原則

1. **圖先於字**：營運中首要辨識靠圖示；名稱僅作輔助（可選 tooltip／準備選單詳情）。
2. **同一套圖、多處複用**：所有顯示同一 SKU 的地方用同一 icon asset（可縮放、可加角標）。
3. **讀得遠、對得快**：在 64px 格點世界與 HUD 上，相鄰 SKU 仍可一眼分開。
4. **回饋瞬間可讀**：找不到／交付成功／交付錯誤用「圖示 + 狀態符」彈出，不靠長句。
5. **美術可換皮**：v1 可用程式化／臨時剪影；正式美術只替換 texture，不改邏輯契約。

### 技術契約（實作時）

- Asset 路徑建議：`res://sprites/sku/<id>.png`（或 atlas `sku_icons.tres`）
- 邏輯鍵：**永遠用 sku id**（`can`…），不要用中文檔名
- 基準畫布：**32×32**（邏輯像素）；匯出可 64×64／128×128，遊戲內縮放
- 透明底；主體置中，四周留 ≥2px 安全邊
- 需支援：彩色、灰階（未開發／不可用）、角標疊加（×？ ✓ ✕ 數量）

## 4. HUD：玩家手持貨品序列

### 行為

- 對應 `inventory.items` 的 **箱／件序列**（與現行 `grouped()`／`boxes()` 一致）。
- 由下而上或由左而右：**先丟的一端（trailing）要一眼可辨**——建議 **右側／末端 = 下一次丟掉的 SKU**（與現行 trailing_run 對齊）。
- 每一「段」：`[icon] ×n`（n 為連續同 SKU 件數；跨箱可拆成多段或合併——**建議合併同 SKU 連續段**，與 `grouped()` 一致）。
- 空手：不顯示列，或顯示空槽虛線（擇一；建議 **不顯示** 以減少雜訊）。
- 超重／負重：沿用現有負重提示；icon 列本身不變色，除非另有「不可再取」狀態。

### 版面（示意）

```
┌─────────────────────────────────────────────┐
│ 時計／營業額／狀態（既有）                      │
│                                             │
│                         ┌手持┐              │
│                         │🥫×4│零食×2│杯麵×1│ ← 末端=下一丟
│                         └────┴──────┴──────┘│
└─────────────────────────────────────────────┘
```

建議錨點：**螢幕右下或角色附近 HUD 區**（勿擋仮想搖桿／暫停）。手機 Web 需避開 TouchPad。

## 5. 客人購物清單（圖畫介面）

### 行為

- 取代（或大幅縮小）現行頭頂純文字清單。
- 顯示 **尚待取得** 的 `shopping[]`（不是已入 `cart` 的已取貨——已取貨可用淡勾或隱藏，避免與待取混淆）。
- **目前目標**（`shopping[0]`）：外框高亮／輕微放大／底色條。
- 清單為空且前往付款：清單列可改為單一「去付款」符號或隱藏（與現行 mood 文案並存一版即可）。

## 6. 彈出回饋（世界空間／短時）

三種皆為：**SKU 小圖示 + 狀態符**，約 0.7–1.1 秒淡出，錨在客人頭上方（可略偏清單列）。

| 事件 | 觸發（現行邏輯） | 視覺 | 狀態符 |
| --- | --- | --- | --- |
| 找不到 | 客人 THINK「找不到」 | icon + 交叉問號 | `？` 上疊 `✕`，或 `？` 加斜劃 |
| 交付成功 | 方向丟掉且 SKU 在清單上被收下 | icon + Tick | `✓` |
| 交付錯誤 | 丟掉碰到客人但 SKU 不在清單／未收下 | icon + 交叉 | `✕` |

規則：

- 一次只顯示一則；新事件打斷舊彈出。
- 不播長文字；SFX 可沿用既有交貨／拒絕音（若有）。
- 顏色：成功用肯定色、錯誤／找不到用警告色——具體色值交美術；程式用 theme／modulate 槽。

## 8. 設計師跟進指引（後續版本精修）

### 交付物

| 項目 | 規格 |
| --- | --- |
| 單品 icon | 每 SKU 至少 1 張；建議 32 與 64 兩檔或單一高清縮放 |
| Atlas（可選） | 一張雪碧圖 + `sku`→rect 對照表 |
| 狀態符 | Tick、交叉、交叉問號（透明底，可疊在 icon 右下） |
| 風格說明 | 一頁：線寬、陰影、是否描邊、可否透視 |

### 風格建議（給美術，非鎖定）

- 頂視便利店／像素偏寫實皆可，但 **9 個 SKU 必須同一風格**
- 避免依賴色盲不友善的「只靠色差」——形狀差是第一分辨力
- 凍櫃／冰櫃類可加小小「冷氣」高光，但仍以輪廓為主
- 勿在 icon 內寫中文字

### 驗收清單（美術）

- [ ] 32px 下 9 種兩兩可辨  
- [ ] **零食 vs 牛奶**：軟袋鋸齒頂 ≠ 硬盒尖屋脊＋倒出口（灰階仍可分）  
- [ ] 灰階仍可辨（無色盲模式）  
- [ ] 疊 `✓`／`✕`／`？✕` 不遮住主輪廓  
- [ ] 透明邊緣無髒邊  
- [ ] 檔名／id 與上表一致  

### 工程替換步驟（美術交付後）

1. 放入 `res://sprites/sku/`（或指定 atlas）  
2. 對照表只改資源路徑，不改 `tuning` id  
3. 截圖對照本檔 §3 位置地圖做一輪 HUD／客人／彈出回歸
