## 1. 目標與原則

1. **圖先於字**：營運中首要辨識靠圖示；名稱僅作輔助（可選 tooltip／準備選單詳情）。
2. **同一套圖、多處複用**：所有顯示同一 SKU 的地方用同一 icon asset（可縮放、可加角標）。**色相一律跟 `Tuning.SKU_COLOR`／`SkuIcons.texture`**（補貨點、貨架、客人／小偷清單、玩家持貨、彈出）；高亮用放大／外框／底條，**不要**用 `modulate` 改圖示顏色。
3. **讀得遠、對得快**：在 64px 格點世界與 HUD 上，相鄰 SKU 仍可一眼分開。
4. **回饋瞬間可讀**：找不到／交付成功／交付錯誤用「圖示 + 狀態符」彈出，不靠長句。
5. **美術可換皮**：v1 可用程式化／臨時剪影；正式美術只替換 texture，不改邏輯契約。

### 技術契約（實作時）

- Asset 路徑建議：`res://sprites/sku/<id>.png`（或 atlas `sku_icons.tres`）
- 邏輯鍵：**永遠用 sku id**（`can`…），不要用中文檔名
- 基準畫布：**32×32**（邏輯像素）；匯出可 64×64／128×128，遊戲內縮放
- 透明底；主體置中，四周留 ≥2px 安全邊
- 需支援：彩色、灰階（未開發／不可用）、角標疊加（×？ ✓ ✕ 數量）

## 4. 角色旁：玩家持貨 Ambient（身下五格／焦點）

螢幕常駐持貨列已改為**跟角色**的 `player_carry_strip`（耐力條下面）。見 [`player-context-ui.md`](player-context-ui.md)。

### 行為

- 對應持貨**合併列**（同 SKU 一格；`grouped()`／slots；列序＝最近觸碰）。
- **平常：** 只顯示**焦點一格**；空手隱藏。
- **長按 LB／鍵 Y·I：** 展開固定 **5 格**，中間第 3 格＝焦點：`[−2][−1][FOCUS][+1][+2]`；焦點可放大 5–10%。總種類 >5 循環捲入。
- 世界持箱：焦點 SKU 箱層在**最下**（貼近角色），紙箱＋面貼小圖約 **1.25×** 並輕微跳動；繪製時畫在**最上層**。
- 每一格：`[icon] ×n`；金框＝焦點。
- 超重／負重：沿用現有負重提示。
- 觸控切焦點：本輪後補。

### 版面（示意）

```
        （角色）
     ████ 耐力
  [−2][−1][焦][+1][+2]   ← 僅展開時；平常只見焦點格
```

錨點：**角色腳下**（唔佔螢幕底欄）。

## 5. 客人／小偷購物清單（圖畫介面）

### 行為

- 取代（或大幅縮小）現行頭頂純文字清單。一般客人與小偷同一套。多重影分身**沒有**購物清單圖示、也沒有不滿條（頭上只寫「分身收銀」／「分身補貨」；見 `shadowclone.md`）。
- 顯示 **尚待取得** 的 `shopping[]`（不是已入 `cart` 的已取貨——已取貨可用淡勾或隱藏，避免與待取混淆）。
- **目前目標**（`shopping[0]`）：輕微放大＋底色條（或外框）；**不改** icon 本身色相。
- 清單為空且前往付款（或小偷得手離場）：清單列可改為單一「去付款」符號或隱藏（與現行 mood 文案並存一版即可）。

### 版面（示意）

```
        ┌──客人／小偷──┐
        │  [🥫] [杯] [雪]  │  ← 待取；首項高亮
        │   ▲目標          │
        └────────┘
```

## 6. 彈出回饋（世界空間／短時）

三種皆為：**SKU 小圖示 + 狀態符**，約 0.7–1.1 秒淡出，錨在客人頭上方（可略偏清單列）。

| 事件 | 觸發（現行邏輯） | 視覺 | 狀態符 |
| --- | --- | --- | --- |
| 找不到 | 客人 THINK「找不到」 | icon + 交叉問號 | `？` 上疊 `✕`，或 `？` 加斜劃 |
| 交付成功 | 方向丟掉且 SKU 在清單上被收下 | icon + Tick | `✓` |
| 交付錯誤 | 丟掉碰到客人但 SKU 不在清單／未收下 | icon + 交叉 | `✕` |

規則：

- 一次只顯示一則；新事件打斷舊彈出。
- 不播長文字；SFX 可沿用既有交貨／拒絕音（若有）。
- 顏色：成功用肯定色、錯誤／找不到用警告色——具體色值交美術；程式用 theme／modulate 槽。

## 8. 設計師跟進指引（後續版本精修）

### 交付物

| 項目 | 規格 |
| --- | --- |
| 單品 icon | 每 SKU 至少 1 張；建議 32 與 64 兩檔或單一高清縮放 |
| Atlas（可選） | 一張雪碧圖 + `sku`→rect 對照表 |
| 狀態符 | Tick、交叉、交叉問號（透明底，可疊在 icon 右下） |
| 風格說明 | 一頁：線寬、陰影、是否描邊、可否透視 |

### 風格建議（給美術，非鎖定）

- 頂視便利店／像素偏寫實皆可，但 **9 個 SKU 必須同一風格**
- 避免依賴色盲不友善的「只靠色差」——形狀差是第一分辨力
- 凍櫃／冰櫃類可加小小「冷氣」高光，但仍以輪廓為主
- 勿在 icon 內寫中文字

### 驗收清單（美術）

- [ ] 32px 下 9 種兩兩可辨  
- [ ] **零食 vs 牛奶**：軟袋鋸齒頂 ≠ 硬盒尖屋脊＋倒出口（灰階仍可分）  
- [ ] 灰階仍可辨（無色盲模式）  
- [ ] 疊 `✓`／`✕`／`？✕` 不遮住主輪廓  
- [ ] 透明邊緣無髒邊  
- [ ] 檔名／id 與上表一致  

### 工程替換步驟（美術交付後）

1. 放入 `res://sprites/sku/`（或指定 atlas）  
2. 對照表只改資源路徑，不改 `tuning` id  
3. 截圖對照本檔 §3 位置地圖做一輪 HUD／客人／彈出回歸
