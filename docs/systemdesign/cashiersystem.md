#收銀系統設定
- 此檔案包含收銀系統設定

#**收銀機**
收銀機為商店物品（程式 id：`cashier`）
預設商店最少要有一台**收銀類**機台（`cashier` 或自助收銀機 `self_cashier`）。店舖設計裡兩者都沒放置，就不能開始營業。
玩家可以在商店準備回合購入額外收銀機
收銀機用作玩家親收／店員綁定收錢之用（自助機見下「自助收銀機」；**不可**對自助機做方向收銀、**不可**綁店員）

#**收銀機與客人的互動**
客人在完成購物清單後會自動前往收銀機排隊。玩家方向丟掉把清單交齊時同理立刻去排隊（見 `playeraction.md`／`customer.md`）。Yes! My Lord! 會讓清單未完成的客人也立刻來排隊；收銀仍要輸入指令，只計客人實際拿走的貨。全體集資會略過指令和 Circle，馬上按已拿走的貨全額入帳，未買到的貨不入帳，客人當已付款離開。主動技 **割韭菜**（`harvest_chives`）要對準一台收銀機：只清該隊 QUEUE／PAYING 前 N 人（同集資入帳；走位中不算；見 `playeractiveskills.md`）。**落閘放狗**會清掉未取完的清單、趕有貨客人來排隊（仍要一般收銀）；空手客人直接離店、不排隊（見 `playerultimateskills.md`）。
客人在收銀機前方排隊
一台收銀機能排客人數目並無上限
如果收銀機已有客人排隊, 下一名客人會排在前一名客人後面
前客入帳離隊後，後方客人**立刻對位**到新站位（隊列壓縮），新隊首須在站位 0 附近才可開始收銀；已入隊微調用直線移動，不走 A* 繞去另一隊。

#**客人排隊與不滿值**
客人進入排隊隊伍後會開始**增加**不滿度（起始 0、上限 100，見 `customer.md`）
純排隊由 0 到 100 需要 15 秒（每秒 +100/15）
壞掉的自助收銀機隊伍為 **2×**（約 7.5 秒滿）；付款中壞機另一次 **+50**（見下「自助收銀機」）
如果一直不完成該客人的收銀動作不滿度會一直累積
客人不滿度到 100 時會顯示生氣動作並離開商店

#**收銀機與玩家角色的互動**
角色在收銀機後方收銀
玩家長按行動鍵進入行動指令狀態
僅當隊伍最前端的客人已經走到收銀機前方時, 才能進入收銀指令
客人完成清單但還在前往收銀機途中時, 不能開始收銀指令

#**收銀行動指令**
進入行動指令狀態後玩家要長按行動鍵, 如果行動中途放手, 已輸入的指令會完全重置, 再互動時要重新動作.
進入行動指令狀態時, 玩家要按方向鍵輸入指令（左搖桿／鍵盤 WASD／虛擬搖桿；**開啟期間 D-PAD 暫借**給指令，不當道具袋——見 `control.md`／`opsitems.md`）
能輸入的指令有:上, 下, 左, 右
輸入指令時玩家角色不會移動
一筆收銀完成後若仍長按：隊首已就緒則**立刻接下一位**指令串；若當下沒有可收客人（空機／客人還在走位），則**解除移動鎖**（仍按住只算未放手；客人就緒後可再自動進指令）
整個收銀行動指令串會顯示在角色頭上等待輸入
每完成一個指令, 已完成的指令圖示會改變顏色
Xbox 的 X／Y／A／B 不作方向；方向用左搖桿／WASD／VJ，指令模式中另可讀 D-PAD。

#**收銀行動指令機制**
每次要輸入的指令**隨機**生成（上／下／左／右均勻），**可連續重複**同一方向。
按照客人購買物品數量生成要輸入指令的**底數**，再由 INT 減次（見下）。
指令次數底表:
| 物品數量| 指令底數|
| ------------- |:-------------:|
|1–5件|7次|
|6件或以上|8次|
INT 減次數（效果用 `min(INT, 50)`；配點可更高，本系統效果頂仍 50）：達到 INT 20／30／40／50 分別再累加 −2／−1／−1／−1（最多 −5）。最終次數 = `max(2, 底數 − INT減)`。
**資深收銀員**不再改指令次數；改為期間雙人結算：親收後對佇列下一位 `QUEUE`／`PAYING` 依機率一併入帳離店（入帳後不得再入隊）；見 `playeractiveskills.md`。
**收銀速度增加**被動：僅在 **Perfect** 親收後，下一客指令串切走頭 1／1／2 格，頭上只顯示餘下箭（LV1／2／3）；撳錯即還原完整串並中斷連鎖；見 `playerpassiveskills.md`。

## 頭目戰同趟多波付款
頭目可覆寫為**同一趟排隊、多波指令串**（波間插演出）；每波為**絕對指令數**（不套 INT 減次／預填／雙收）。全體集資／割韭菜／Self Checkout／店員／影分身代收對該頭目**無效**。詳見 [`bossbattle.md`](bossbattle.md) 與各 [`bosses/`](bosses/) 專檔（測試：外星大土豪 5→6→10）。

#**完成收銀行動指令**
如果有任何一個指令輸入失敗, 整串指令要由頭輸入 (保持同一串指令)
指令失敗時會在輸入錯的指令圖示顯示X
直至所有收銀行動指令正確輸入才算完成
**沒有 Loading Circle**：最後一箭正確（或預填後整串已完成）即入帳；仍須維持長按行動至完成，中途放手重置指令串。
收銀動作完成後會彈出$圖示；完成後仍長按的銜接／可走規則見上「輸入指令時」段。
預留 Perfect／節奏評級擴充（而家只有 perfect／ok 標記與營業額倍率；特效之後再加）。

#**收銀與 INT／營業額**
玩家親收營業額：`payout × (1 + INT營業額% + 人肉數錢機%) × (Perfect 則 ×1.05)`。
INT 營業額階梯（效果頂 50）：10→0%、20→5%、30→10%、40→15%、50→20%。
店員／Dark Side 臨時／Self Checkout／影分身代收：就緒即入帳（無箭頭、無玩家 Circle）；**不套**玩家 INT／人肉／Perfect／預填／雙收。影分身見 `shadowclone.md`。

#**多台收銀機：客人選隊**
客人完成購物後前往收銀（候選含普通 `cashier` **與**自助 `self_cashier`，含壞機自助機）：
1. 選**排隊人數最短**的一台
2. 人數相同 → 選**距離最近**的一台
3. 距離也相同 → **隨機**一台

店員各看自己那台（僅 `cashier`；見 `clerksystem.md`）。Dark Side 臨時與影分身就緒即收（**不可**佔自助機）。兩者都不擋住玩家親自收那台普通收銀。

#**增加營業額**
成功完成收銀行動後, 貨品的售價總數（再乘上述 INT／技能／Perfect 倍率，僅親收）會加到營運回合中的營業額
貨品的售價參考貨品價格設定
被小偷帶走、未收銀的貨不算營業額，另計被偷統計（見 `thiefsystem.md`）。
營業額不會即時加到商店資金
商店資金會在店舖結算後才會增加
## Self Checkout（主動技／奧義；限時）
主動技能可於施放時啟動5身位內**普通** `cashier` 15秒，離開仍運作；每台逐客自助5／4／3秒，真人及NPC優先並取消自助進度。到期只收完已開始的尾單。詳見 `playeractiveskills.md`。自助倒數與客人綁定，強制結帳及離隊不能把進度帶給下一客，亦不能重複入帳。對象不含傢俬 `self_cashier`（該機台本身已是自助，節拍不變）。

#**自助收銀機**（傢俬 `self_cashier`）
- Catalog／價／佔格／章節放置上限預留：見 [`shopitem.md`](shopitem.md)
- **不是**主動技 Self Checkout；永久放置、營業期間持續嘗試自動化付款
- 交叉：`playeraction.md`（維修）、`customer.md`（壞機排隊不滿）、`clerksystem.md`（不可綁定）、`ratingsystem.md`、`soundeffects.md`

## 運作與付款
- 隊首就緒後自動開始付款倒數：**約 10 秒／客**（固定；不吃 INT／Perfect／預填／雙收／人肉）
- 玩家**不可**對自助機做方向收銀；運作中無需玩家互動
- 入帳規則對齊技能 SCO：非完美；評價普通客 **+1**／麻煩客 **+10**（不另加完美）；**不掛**玩家 seat XP；任務 metric `checkout_count` 仍可計
- 頭目多波付款：自助機對頭目**無效**（同技能／店員代收；見 `bossbattle.md`）
- Dark Side／多重影分身**不可**佔自助機
- 主動技 Self Checkout／奧義「有糧出無汗出」**不改變**自助機的 10 秒節拍

## 運作值（血量）
- 上限／每次開店起點：**100**（開店重置為 100；當日維修後的剩餘值保留至關店）
- 隊首付款倒數期間**持續**扣減；整段約 **20 點／客**（建議 **2／秒 × 10 秒**，實作可調 `Tuning`；滿值 100 → 約 **5 客**壞機）
- `運作值 ≤ 0` → 機台**壞掉**，停止開新付款倒數
- **付款進行中**運作值先歸零（倒數未完成）：該客付款進度**取消**、該客不滿 **+50**，機台進入壞機；該客留在隊首（或依實作回 QUEUE），待維修後才能再付
- 倒數正常完成且當下仍可入帳：成功入帳後若運作值已 ≤ 0，機台同樣進壞機（該客**已付**，不另加 +50）

## 壞機排隊
- 壞機時客人**仍可選隊與排隊**，但不能開始／完成付款
- 排在壞機隊的不滿累積為一般排隊的 **2×**（一般 0→100＝15 秒 → 壞機約 **7.5 秒**；見 `customer.md`）
- 直至該台維修完成（運作值 > 0）才恢復自動付款

## 維修動作
- 只要運作值 **< 100**（有下降），玩家便可走近對準機台按**行動鍵**進入維修（含尚未壞機的中途保養；空手／持貨皆可；見 `playeraction.md`）
- **互斥：**
  - **客人使用中**（自助付款倒數進行中）→ **不可**開始維修
  - **維修中** → 客人**不可**開始／繼續付款（隊列可留；同壞機不能付）
- 機台上方顯示一條維修 BAR；遊標左右來回（建議約 **1.5 來回／秒**，實作可調 `Tuning`）
- BAR 由左至右七區：**空白 → 紅 → 黃 → 綠 → 黃 → 紅 → 白**
- 玩家瞄準後再按**行動鍵**輸入一次即結算該區並加運作值（上限 100）：

| 區 | 加運作值 |
| --- | ---: |
| 綠 | +40 |
| 黃 | +20 |
| 紅 | +10 |
| 白 | +5 |
| 空白 | +10 |

- **連續維修：** 命中後若運作值仍 < 100，BAR 繼續、遊標重開下一輪；再按行動鍵繼續，直到**完全修好（100）**或中途按**取消鍵**離開
- 取消離開不加當下這一擊的運作值；已加上的保留。運作值仍 ≤ 0 則機台仍壞；已 > 0 且未在維修則可自動付款；未滿 100 且無人付款時可再進維修補滿
- 維修結束且運作值 > 0、隊首仍就緒時，可立刻重開 10 秒付款倒數
