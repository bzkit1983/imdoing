#收銀系統設定
- 此檔案包含收銀系統設定

#**收銀機**
收銀機為商店物品
預設商店最少要有一台收銀機。店舖設計裡沒有放置收銀機，就不能開始營業。
玩家可以在商店準備回合購入額外收銀機
收銀機用作收錢之用

#**收銀機與客人的互動**
客人在完成購物清單後會自動前往收銀機排隊。Yes! My Lord! 會讓清單未完成的客人也立刻來排隊；收銀仍要輸入指令，只計客人實際拿走的貨。全體集資會略過指令和 Circle，馬上按已拿走的貨全額入帳，未買到的貨不入帳，客人當已付款離開（見 `playerultimateskills.md`）。
客人在收銀機前方排隊
一台收銀機能排客人數目並無上限
如果收銀機已有客人排隊, 下一名客人會排在前一名客人後面

#**客人排隊與不滿值**
客人進入排隊隊伍後會開始**增加**不滿度（起始 0、上限 100，見 `customer.md`）
純排隊由 0 到 100 需要 15 秒（每秒 +100/15）
如果一直不完成該客人的收銀動作不滿度會一直累積
客人不滿度到 100 時會顯示生氣動作並離開商店

#**收銀機與玩家角色的互動**
角色在收銀機後方收銀
玩家長按行動鍵進入行動指令狀態
僅當隊伍最前端的客人已經走到收銀機前方時, 才能進入收銀指令
客人完成清單但還在前往收銀機途中時, 不能開始收銀指令

#**收銀行動指令**
進入行動指令狀態後玩家要長按行動鍵, 如果行動中途放手, 已輸入的指令會完全重置, 再互動時要重新動作.
進入行動指令狀態時, 玩家要按方向鍵輸入指令（鍵盤 WASD、手制十字／搖桿、虛擬搖桿）
能輸入的指令有:上, 下, 左, 右
輸入指令時玩家角色不會移動
整個收銀行動指令串會顯示在角色頭上等待輸入
每完成一個指令, 已完成的指令圖示會改變顏色
Xbox 的 X／Y／A／B 不作方向；方向一律用搖桿／十字／WASD。

#**收銀行動指令機制**
每次要輸入的指令隨機生成
按照客人購買物品數量生成要輸入指令的次數
購買物品數量越多, 指令的次數越多
指令次數生成公式:
| 物品數量| 指令次數|
| ------------- |:-------------:| 
|1-2件|1次|
|3-5件|2次|
|6-8件|3次|
|9-10件|4次|
|11件或以上|5次|
指令次數上限為5次

#**完成收銀行動指令**
如果有任何一個指令輸入失敗, 整串指令要由頭輸入 (保持同一串指令)
指令失敗時會在輸入錯的指令圖示顯示X
直至所有收銀行動指令正確輸入才算完成
完成所有指令後才會出現"Loading Circle"完成整個收銀動作
收銀動作完成後會彈出$圖示

#**收銀行動時間**
收銀 Circle：INT 10＝2 秒，INT 50＝0.2 秒，中間線性（見 `playerstats.md`）。
角色 INT 值越高收銀時間越快（INT 50 後不再因 INT 加快）。
收銀速度技能／被動加在 INT 算出的時間之後。

#**增加營業額**
成功完成收銀行動後, 貨品的售價總數會加到營運回合中的營業額
貨品的售價參考貨品價格設定
被小偷帶走、未收銀的貨不算營業額，另計被偷統計（見 `thiefsystem.md`）。
營業額不會即時加到商店資金
商店資金會在店舖結算後才會增加
