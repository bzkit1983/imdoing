# 貨品培育收成獎勵

選料頁的「獎勵機率」先提供預覽。實際獎池內容定案前，照常派發現有培育收成。

確認投入時先按原配方等機率抽出一件候選貨品。當時未開發的候選貨品按原定規則於收成時入倉一件並解鎖。確認後才付費開發該貨品，仍可領取原定的一件貨品。配方不存在或候選貨品當時已開發，才抽選獎勵分類。

獎勵分類使用 `CULTIVATION_REWARD_WEIGHTS`。正式啟用時，在確認投入時均勻抽取 1 至 10,000 的整數，以累計權重決定分類，再按獎池規則抽出品項。獎勵與扣除原料同次存檔，領取時才揭曉。讀檔、延遲領取及付費開發均沿用已存結果。

退料分類從每件投入原料等機率抽出一件，重複投入的品項會按件數增加機率。Lv. 4–8 商品沿用現有開發門檻分類，包括支裝凍飲、牛奶、汽水、雪糕及凍肉。

各獎池品項、池內權重、重複獎勵處理，以及 Lv. 4–8 商品池可否抽中未開發貨品，待逐類定案後才啟用派獎。
