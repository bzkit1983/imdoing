# 輸入三態與虛擬搖桿（VJ）— PM／測試說明

> 活線：`godot/game`  
> 工程：Autoload `InputMode`、`PlatformServices`；UI `scripts/touch_pad.gd`  
> 相關：`control.md`、`pausemenu.md`、`storepreparationphase.md`

## 一句話

遊戲分三種活躍輸入：**觸控（VJ）／實體手掣／鍵盤**。螢幕虛擬搖桿**預設關閉**；玩家可在準備「系統工具」或**暫停選單**打開。打開後只在觸控活躍時顯示；一用實體手掣或鍵盤就自動隱藏，唔會遮畫面。

## 三態

| 狀態 | 點樣進入 | 螢幕 VJ |
| --- | --- | --- |
| **觸控** | 螢幕觸控／滑鼠點畫面 | 若玩家已開「虛擬搖桿」→ **顯示** |
| **實體手掣** | 手掣掣／搖桿有效輸入 | **隱藏** |
| **鍵盤** | WASD、J/K/L/;／U 等營運鍵 | **隱藏** |

- 顯示公式：`設定虛擬搖桿＝開` ∧ `活躍＝觸控`
- Desktop 編輯器亦可開 pref 預覽 VJ（預設仍關，唔會無端彈出）
- **唔會**只因為「插咗手把」就隱藏（避免幽靈裝置誤判）；要以**實際手掣輸入**為準

## 玩家可改邊度

| 入口 | 位置 | 說明 |
| --- | --- | --- |
| 準備階段 | 系統工具 →「虛擬搖桿：開／關」 | 原本已有；寫入 `user://settings.cfg` |
| 營運中 | 暫停選單 →「虛擬搖桿：開／關」 | **今次新增**；Desktop／Web／手機都有；與上面同一設定 |
| 預設 | **關** | 跟 tester／PM：開局唔應見到 VJ |

## 開啟後畫面長點（LoL 手機式）

橫向螢幕為準；左右簇會跟畫面縮，中間留空，避免遮店舖：

- **左下：** 移動虛擬搖桿  
- **右下大核：** 行動（短／長按語意同 J／A）  
- **行動左：** 衝刺／跑  
- **行動上：** 取消／丟貨  
- **最上：** 奧義  
- **技1–技5：** 由左往上往右上極座標扇形直放（技1＝中間技能；技2–5＝LB／RB／LT／RT）。無另設「技能選單」掣（鍵盤 L／手掣 Y 長按仍可用）
- **自己微調排位：** 改 [`touch_pad.gd`](../../godot/game/scripts/touch_pad.gd) 頂部 `LAYOUT_*` 常數（相對「行動」中心；角度 Y-down）。暫未做拖曳編輯器；要再貼參考圖可叫開發改數字或之後加 debug 拖掣
## 測試清單（建議）

1. Web／手機新檔（或清 `user://settings.cfg`）：開營運日 → **唔見** VJ  
2. 暫停 → 開虛擬搖桿 → 見 LoL 式左右簇；中間店舖大致淨空  
3. 接 Xbox 郁搖桿／撳 A → VJ **消失**；手掣操作正常  
4. 再觸控螢幕（且設定仍開）→ VJ **返嚟**  
5. 用鍵盤 WASD／J → VJ 隱藏  
6. 準備「系統工具」開關與暫停開關狀態一致（同一 pref）  
7. Desktop 編輯器：暫停有「虛擬搖桿」開關；開咗之後用滑鼠點畫面應見到 LoL 式 VJ；撳 WASD／手掣會隱藏  

## 工程對照（開發用）

- `InputMode`：`show_vj()` / `mode_changed` / `clear_virtual_holds`
- Pref：`[ui] virtual_stick`（預設 `false`）
- 舊 API `PlatformServices.show_touch_pad()` 會轉去 `InputMode.show_vj()`
