# 麻煩客人設定（EliteCustomer）

- 此檔案包含麻煩客人（EliteCustomer）設定
- 工程代號：`EliteCustomer`（活線尚未實作；本檔為設計稿）
- 一般客人規則見 `customer.md`；污物見 `cleaningsystem.md`；丟掉交付見 `playeraction.md`
- **狀態：設計中。** 「# 未決／待拍板」未關閉前不實作

# 定義

麻煩客人是**客人的一種**（不是小偷）：
- 基本流程與一般客人相同：有購物清單 →（多數情況）自行取貨 → 清單完成後往收銀處排隊付款
- 與一般客人的分別：
  1. 購物清單件數依等級乘上係數（比同回合一般客人基準**多／大** 2～5 倍，見等級表）
  2. 依等級附加若干**詞綴負面行為**
  3. 進場有專屬提示與造型，易於分辨

麻煩客人**有不滿度**、**佔在店客人數**、踩污物受一般客人規則影響（與小偷相反）。

# 等級

| 等級 | 購物清單相對一般客人 | 負面行為（詞綴）數 |
| --- | --- | --- |
| LV1 | ×2 | 1 |
| LV2 | ×2.5 | 2 |
| LV3 | ×3 | 3 |
| LV4 | ×3.5 | 4 |
| LV5 | ×4 | 5 |
| LV6 | ×5 | 6 |

- 「相對一般客人」＝以該局／該次抽清單時，一般客人會抽出的件數為基準再乘係數（非整數則**向上取整**；待拍板見未決）
- 等級隨**劇情進度**開放較高等級；一般營運以低等級為主。事件可指定等級或強制出現（見出現機率）

# 詞綴與負面行為

進場時依等級從下表**隨機抽取**對應數量的詞綴（抽取規則待拍板：是否不重複、詞綴效果等級是否＝客人等級）。

## 破壞貨架

麻煩客人會隨機把**身邊貨架**上的貨品弄下架，貨品掉在地上（僅玩家可撿，見 `customer.md` 地上掉落箱）。

| 詞綴／效果 LV | 弄跌數量 |
| --- | --- |
| LV1 | 該架現有庫存的 50% |
| LV2 | 60% |
| LV3 | 70% |
| LV4 | 80% |
| LV5 | 90% |
| LV6 | **全部購物清單**（原文；與 LV1–5「貨架庫存 %」語意衝突，見未決） |

觸發節奏、身邊範圍、一次打幾架：見未決。

## 煽動不滿

麻煩客人把身邊 **5 身位**內其他客人的不滿度**持續**每秒上升：

| LV | 每秒 +不滿 |
| --- | --- |
| LV1 | +1 |
| LV2 | +2 |
| LV3 | +3 |
| LV4 | +4 |
| LV5 | +5 |
| LV6 | +6 |

- 是否對其他麻煩客人／排隊中／離開中生效：見未決
- 與污物、排隊、找不到貨的不滿**疊加**；滿 100 仍生氣離開
- The World! 期間是否跟世界流速：建議跟一般不滿一樣變慢（待拍板）

## 搗亂購物籃

麻煩客人隨機把身邊客人**已取貨**弄跌到地上；該客人須**從頭取貨**（清單是否重抽：見未決；活線衝刺撞客是**不重抽**清單）。

| LV | 弄跌比例 |
| --- | --- |
| LV1 | 已取貨的 50% |
| LV2 | 60% |
| LV3 | 70% |
| LV4 | 80% |
| LV5 | 90% |
| LV6 | 全部已取貨 |

原文「弄跌 N% 的購物清單」與「重置」並存，語意待拍板。

## 趕客

麻煩客人隨機把身邊客人趕走；該客人不滿度增加：

| LV | 不滿 |
| --- | --- |
| LV1 | +50 |
| LV2 | +60 |
| LV3 | +70 |
| LV4 | +80 |
| LV5 | +90 |
| LV6 | +100 |

- 「趕走」＝加不滿後若 ≥100 則離開，或**強制立刻離店**（即使未滿 100）：見未決

## 垃圾蟲

麻煩客人隨機在附近丟下污物（種類依等級解鎖池）：

| 客人 LV | 可丟種類（從池中隨機） |
| --- | --- |
| LV1–2 | 垃圾 |
| LV3–4 | 垃圾、水漬 |
| LV5–6 | 垃圾、水漬、嘔吐物 |

冷卻、同時污物上限、是否算進 Beta 流量：見未決與 `docs/beta/design.md`。

## 不主動購物

麻煩客人在店內貨架間**遊走**，**不自行**從貨架取貨進購物車。  
要完成清單，須由**玩家主動交付貨品**（活線：方向丟掉命中且 SKU 在清單內，見 `playeraction.md`；Alpha「幫忙取貨／COMBO」若日後實作亦可適用）。

- 仍顯示完整購物清單與不滿度
- 清單被交齊後仍去收銀排隊
- 與其他詞綴並存時是否仍遊走、是否還會站到貨架前：見未決

# 出現機率

- **一般營運回合：** 出現率低，約 **5%–10%**（抽樣單位待拍板：每名進店客人／每波／每回合至少一次檢定）
- **劇情進度：** 越高越可能抽到更高 LV
- **事件：** 可提高機率，或**必定**出現指定 LV／詞綴
- **同回合**可同時存在**多名**麻煩客人（上限待拍板）
- 詳細等級解鎖表、事件表留待劇情／Beta 時補；本檔先定行為框架

# 特效

麻煩客人出現時：
1. 彈出提示：**「麻煩客人注意！」**
2. **ZOOM IN** 到該麻煩客人位置（時長／是否可被其他鏡頭打斷：見未決；可對齊小偷 KO／被偷橫幅的鏡頭習慣）

# 造型

麻煩客人使用**可明顯區分**於一般客人的造型（專用 voxel／配色／配件；具體美術另開）。  
頭頂清單／不滿儀表仍可用一般客人規則，可另加詞綴圖示或名稱標（待拍板）。

# 未決／待拍板

實作前必須拍板。編號供回覆引用。

1. **清單倍數語意：** 「多 2 倍」＝基準×2，還是基準＋2×基準（×3）？本檔暫按等級表寫成 **×2…×5**。
2. **與 15 件上限：** 倍數後可否超過一般客人 15 件上限？還是先乘再 cap 15？Yes! My Lord! 可否再往上加？
3. **基準件數：** 倍數乘的是「該次一般客人會抽到的件數」，還是固定 Demo／長線基準表？
4. **詞綴抽取：** 同客人身上詞綴是否**不重複**？LV6 是否必拿齊全部 6 種？
5. **詞綴效果 LV：** 效果表 LV 是否**永遠等於**麻煩客人 LV？還是詞綴另 roll 1…客人LV？
6. **破壞貨架 LV6：** 原文「弄跌全部購物清單」與 LV1–5「貨架庫存 %」衝突——LV6 是清空目標貨架、還是按自己清單件數從架上扣、還是筆誤應為「弄跌 100% 貨架庫存」？
7. **破壞／搗亂／趕客／垃圾「隨機」節奏：** 進場一次／每 N 秒／每次走到貨架旁？身邊範圍是否同煽動的 5 身位？
8. **搗亂購物籃「重置」：** 清單是否重抽？或與衝刺撞客一致（清單不變，已取貨按比例掉落後放回清單）？
9. **趕客：** 僅加不滿，或不滿未滿 100 也**強制離店**？被趕者是否掉落已取貨？
10. **煽動不滿：** 是否影響其他麻煩客人、已在排隊者、離開中者？多名麻煩客人光環是否疊加？
11. **不主動購物：** 無該詞綴時行為完全同一般客人；有該詞綴時是否**完全禁止**自行取貨？玩家以外（店員／奧義）可否幫他完成清單？
12. **出現檢定：** 5–10% 是每名 spawn 獨立 roll，還是每回合一次？同回合多名上限？補貨時段會否出現？
13. **鏡頭：** ZOOM 時長、是否暫停玩法、與衝刺／打擊鏡頭衝突時誰優先？
14. **獎勵／懲罰：** 成功收完麻煩客人是否有額外經驗或營業額？被其弄跑客人／弄髒是否有額外結算？
15. **版本歸屬：** 行為框架進長線本檔；流量與劇情解鎖表是否標 **Beta**（與 `docs/beta/design.md` 客人流量一致）？
