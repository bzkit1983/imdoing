# 麻煩客人設定（EliteCustomer）

- 此檔案包含麻煩客人（EliteCustomer）設定
- 工程代號：`EliteCustomer`
- 一般客人規則見 `customer.md`；污物見 `cleaningsystem.md`；丟掉交付見 `playeraction.md`
- **狀態：已拍板並落地活線**（`customer.gd`／`demo.gd`／`tuning.gd`）。劇情等級解鎖表／事件強制表標 **Beta**（見 `docs/beta/design.md`）
- 拍板日：2026-10-24
- 活線暫定：`ELITE_MAX_UNLOCKED_LV = 1`（僅 LV1），直至 Beta 解鎖表

# 定義

麻煩客人是**客人的一種**（不是小偷）：
- 基本流程與一般客人相同：有購物清單 →（無「不主動購物」時）自行取貨 → 清單完成後往收銀處排隊付款
- 與一般客人的分別：
  1. 購物清單件數＝該次一般客人會抽出的件數 × 等級倍數（可超過 15；Yes! My Lord! 仍可再加）
  2. 依等級附加若干**不重複**詞綴負面行為（LV6 必拿齊全部 6 種）
  3. 進場有專屬提示、ZOOM、造型

麻煩客人**有不滿度**、**佔在店客人數**、踩污物受一般客人規則影響（與小偷相反）。

# 等級

| 等級 | 購物清單倍數 | 負面行為（詞綴）數 |
| --- | --- | --- |
| LV1 | ×2 | 1 |
| LV2 | ×2.5 | 2 |
| LV3 | ×3 | 3 |
| LV4 | ×3.5 | 4 |
| LV5 | ×4 | 5 |
| LV6 | ×5 | 6 |

- 倍數＝基準件數 × 上表（非整數**向上取整**）
- 基準＝該次若為一般客人會抽出的件數（同一套抽清單邏輯先決定件數，再乘倍數）
- **可超過**一般客人 15 件上限；Yes! My Lord! 搶架仍可再往清單加件
- 等級隨**劇情進度**開放（解鎖表 Beta）；一般營運以已解鎖的較低等級為主。事件可指定等級或強制出現

# 詞綴與負面行為

進場時從六種詞綴中**不重複**隨機抽 N 個（N＝等級對應欄）。LV6＝六種全拿。

**詞綴效果等級（效果表 LV）**預設先跟麻煩客人 LV；**不一定永遠相等**——Beta 平衡時可另做 mapping（例如 LV4 客人抽到「破壞」但效果只用 LV2 表）。長線實作保留「客人 LV」與「各詞綴效果 LV」分開欄位。

身邊「接觸」＝與目標碰撞／貼近到約 **1 身位**內（破壞對貨架；搗亂／趕客對客人）。煽動另用 5 身位光環。

破壞／搗亂／趕客／垃圾蟲：在條件滿足時，每隔 **5～15 秒**（每次觸發後重 roll 間隔）嘗試一次。

## 破壞貨架

在**貨架旁**（接觸貨架）時觸發：把該架現有庫存按比例弄下架，掉在地上（僅玩家可撿）。

| 效果 LV | 弄跌該架庫存 |
| --- | --- |
| LV1 | 50% |
| LV2 | 60% |
| LV3 | 70% |
| LV4 | 80% |
| LV5 | 90% |
| LV6 | **100%（清空該架）** |

件數向下取整；至少在庫存≥1 且比例結果為 0 時是否掉 1：實作取 `maxi(1, floor(stock * pct))` 且不超過現有庫存；LV6 掉光。

## 煽動不滿

持續光環：身邊 **5 身位**內其他客人每秒加不滿。

| 效果 LV | 每秒 +不滿 |
| --- | --- |
| LV1–6 | +1 … +6（同 LV） |

- **影響：** 一般客人；**含排隊中**
- **不影響：** 其他麻煩客人；**離開中**客人；小偷
- **多名麻煩客人光環疊加**
- 與污物／排隊／找不到貨疊加；滿 100 生氣離開
- The World! 期間跟世界流速（與一般不滿相同）

## 搗亂購物籃

在**客人旁**（接觸其他一般客人）時觸發：按比例弄跌其**已取貨**到地上；**購物清單不變**（與衝刺撞客相同），已取貨放回清單後從頭尋貨。

| 效果 LV | 弄跌已取貨比例 |
| --- | --- |
| LV1 | 50% |
| LV2 | 60% |
| LV3 | 70% |
| LV4 | 80% |
| LV5 | 90% |
| LV6 | 100% |

不對其他麻煩客人發動。

## 趕客

在**客人旁**觸發：該一般客人不滿 **+下表**；**不強制離店**。若因此不滿達到 100 → 正常生氣離開，且**已取貨掉地**。

| 效果 LV | +不滿 |
| --- | --- |
| LV1 | +50 |
| LV2 | +60 |
| LV3 | +70 |
| LV4 | +80 |
| LV5 | +90 |
| LV6 | +100 |

不對其他麻煩客人發動。

## 垃圾蟲

在**空地**上（未貼貨架／障礙的可行走格）每隔 5～15 秒丟一種污物；種類從客人**等級**解鎖池隨機：

| 客人 LV | 可丟種類 |
| --- | --- |
| LV1–2 | 垃圾 |
| LV3–4 | 垃圾、水漬 |
| LV5–6 | 垃圾、水漬、嘔吐物 |

## 不主動購物

**完全禁止**自行從貨架取貨。在貨架間遊走；須玩家方向丟掉交付（SKU 在清單）才能完成。  
- **NPC 店員不能**代取／代完成其清單  
- **主動技能／奧義**若效果能填充清單（如 Yes! My Lord!），則可完成並去排隊  
- 清單交齊後仍去收銀

# 出現機率

- **一般營運（open 時段）：** 每名進店客人獨立 roll，**1%–5%**（因已改為每名 roll，由原稿 5–10% 調低）
- **補貨時段（restock）：不出現**
- **同回合人數：無上限**（仍受一般在店客人 cap 約束）
- **劇情解鎖較高 LV、事件提高機率／必出：** Beta（`docs/beta/design.md`）
- 未解鎖較高 LV 前，只從已解鎖等級池抽（無劇情前活線可暫只開 LV1，或 TEST 全開）

## 測試版：麻煩客人模式

準備選單（僅 `TEST_TOOLS`）→ **開始營運（麻煩客人模式）**：
- 可選 **LV1–LV6**（本局該保證出現的／後續抽中的麻煩客人都用此 LV），或 **混合 LV**（每次麻煩客人獨立 roll 1–6，不受 `ELITE_MAX_UNLOCKED_LV` 限制）
- 進入後與一般開店相同確認；**保證至少一名**麻煩客人（營運時段第一位進店客人強制為麻煩客人）
- 其後仍可依一般 1–5% 再出更多麻煩客人

# 特效

出現時：
1. 提示橫幅：**「麻煩客人注意！」**
2. **ZOOM IN** 約 **1 秒**，期間**暫停操作**
3. 若當下有**打擊／衝刺鏡頭**，那些**優先**；完成後再 ZOOM 此麻煩客人

# 造型

專用造型，明顯區分一般客人（可用配色／配件／獨立 sprite id；美術可後換）。頭頂清單／不滿照一般客人；可顯示詞綴摘要。

# 與現有系統

| 系統 | 規則 |
| --- | --- |
| 衝刺撞客 | 同一般客人 |
| 丟掉砸中 | 同一般客人（對清單交付） |
| Yes! My Lord!／全體集資 | **包含**麻煩客人 |
| 在店人數 | **佔**客人名額 |
| 成功收銀（收完此麻煩客人） | **額外經驗**；該筆**營業額 ×2** |
| 被其弄跑其他客人 | **無**額外結算懲罰 |
| NPC 店員 | 不代為完成「不主動購物」清單 |

# 已拍板紀錄（2026-10-24）

1. 倍數＝基準×等級表（×2…×5）  
2. 可超過 15；Yes! My Lord! 可再加  
3. 基準＝該次一般客人抽件數  
4. 詞綴不重複；LV6 全拿  
5. 效果 LV 預設＝客人 LV，Beta 可另 mapping  
6. 破壞 LV6＝清空該架 100%  
7. 節奏與接觸範圍見上  
8. 搗亂＝清單不重抽、只掉已取貨  
9. 趕客＝只加不滿；滿 100 離店且已取貨掉地  
10. 煽動不影響其他麻煩／離開中；影響排隊；光環疊加  
11. 不主動購物＝禁自行取；店員不行；技能／奧義可  
12. 每名進店 1–5%；無同回合人數上限；補貨時段不出  
13. ZOOM≈1s 暫停操作；打擊／衝刺鏡頭優先  
14. 收完額外經驗＋營業額雙倍；弄跑無額外罰  
15. 行為長線；劇情解鎖 Beta
