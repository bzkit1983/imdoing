# 精英店員設定（開檔）

- 此檔案定義**精英店員**（店鋪 NPC 店員的特殊類型）
- **狀態：** 概念開檔；數值／技能表／個別角色詳情**後補**
- 一般雇員：[`clerksystem.md`](clerksystem.md)
- 劇情框架／主題通關來源：[`storysystem.md`](storysystem.md)、[`story/themes/`](story/themes/)

# 與一般雇員的差異

| 項目 | 一般雇員（`clerksystem`） | 精英店員 |
|------|---------------------------|----------|
| 身份 | 可雇 NPC；無固定劇情名 | **有名稱**、有劇情背景 |
| 取得 | 規模內雇用（日薪） | 主題通關為主；另有非劇情來源 |
| 等級 | 無獨立投資等級 | **可投資升級**（資金／素材待表） |
| 能力 | 崗位固定行為；補貨等用固定 AGI 等 | 能力隨等級提升；**限定技能組**（類玩家，但有範圍限制） |
| 崗位 | restock／cashier／security／cleaner | 詳後補（可跨崗位或主題專長） |
| 上限 | `HIRE_CAP`／規模 | 與一般雇員欄位關係待定（是否另占欄、可否並行） |

# 來源（框架）

1. **劇情／主題：** 完成每個可選主題（及是否含破局）後獲得該主題**主導精英店員**——一般規則；個別例外後補  
2. **非劇情：** 小遊戲獎勵、特別事件任務——可獲得不綁主題主線的精英店員  

詳表（角色 id、所屬 `theme_id`、技能池、升級曲線）：**後補**。

# 框架槽位（設計時填）

| 槽位 | 說明 |
|------|------|
| `elite_clerk_id` | 穩定 id |
| 顯示名／背景 | 劇情短述 |
| `source` | `theme_clear`／`minigame`／`event`／… |
| `theme_id` | 若主題主導則填；非劇情可空 |
| 初始等級／等級上限 | 待表 |
| 投資費用曲線 | 待表 |
| 限定技能組 | 可裝備的主動／被動子集（COST 規則待定） |
| 外觀／模型 | skin id |

# 與其他系統

- 不取代麻煩客人（`elitecustomer.md`＝客人壓力單位）
- Dark Side／影分身臨時人力**不是**精英店員
- 存檔：已擁有列表、各員等級／投資進度（schema 待 `savesystem.md`）
