#**操作設定**
- 此檔案包含操作設定
- Demo 實作範圍與試玩數值以 `docs/demo/` 各版本 scope 為準（v0.3 起已實作下列營運回合操作；清潔見 v0.4，打擊見 v0.5）
- **v1 活線工程：** `godot/game`。輸入以 Godot **InputMap action** 為準（Autoload `Controls`）。鍵盤／手制／觸控都對到同一套 action；下列鍵位是**預設綁定**，可在專案設定改鍵，不改玩法邏輯。
- **手制裝置：** 單機時 Xbox 預設綁定的 InputMap `device` 為 **-1（任何已連接手把）**；左搖桿輪詢走 `Input.get_connected_joypads()`，不寫死 device 0。Windows 常把 Xbox 編成 0 以外的裝置（XInput + DirectInput 雙重列舉、虛擬／幽靈手把佔 0），Mac 則多半就是 0。
- **本機雙人（M1）：** Seat0＝手把 **device 0**，Seat1＝手把 **device 1**。鍵盤可佔**尚未被手把綁定**的 seat；兩 seat 都已被手把佔用時鍵盤無效。詳見 `multiplayer.md` §11.4。
- 主要 action：`move_up`／`move_down`／`move_left`／`move_right`、`interact`、`cancel`、`dash`、`skill`、`ult`；Xbox 肩鍵快捷 `skill_2`／`skill_3`（LB／RB）；Xbox 奧義為 LT+RT 長按（輪詢板機軸，非 InputMap）；準備店舖設計另有 `rotate`；補貨快捷有 `restock_prev`／`restock_next`／`restock_slot_1..3`；鏡頭視野循環 `camera_view`（鍵盤 `V`、Xbox 視圖鍵／`JOY_BUTTON_BACK`）
- **暫停選單：** 營運日 Esc／手把 Start 開關（見 `pausemenu.md`）。本機雙人時**任一 seat** 都可開／關。選單內移動／確定／取消仍走 `move_*`／`interact`／`cancel`
- **UI 文案：** 準備／暫停／HUD 等已遷字串表者走 Autoload `Loc`（`docs/alpha/i18n.md`），與鍵位無關

#**遊玩視點**
- 以俯瞰視角觀察商店
- 鏡頭預設追蹤玩家角色隨角色移動（全地圖模式除外）
- **本機雙人（M1，見 `multiplayer.md` §11）：** 鏡頭**永遠跟隨兩可控角色的中點**；不做焦點切換。全地圖仍鎖店中心。
- 三種可調視野（暫停選單循環，或營運中 `camera_view`：鍵盤 `V`／Xbox 視圖鍵）。寫入 `user://settings.cfg` → `[ui] camera_view`；改完立刻生效，跨營運日保留
- - **正常**（`normal`，預設）：Camera2D zoom **1.22**，跟隨玩家（雙人時為中點）
- - **稍遠**（`far`）：固定 zoom **0.95**，跟隨玩家（雙人時為中點），可見範圍略大於正常
- - **全地圖**（`overview`）：依當日店舖地板尺寸與 viewport 計算 zoom（約 8% 邊距），鏡頭**鎖在店中心**、不跟隨玩家
- HUD 與虛擬鍵不隨世界放大
- 施放技能／奧義時鏡頭會短暫再 ZOOM IN，然後回到**當前視野**基值
- 抓住小偷打擊時鏡頭再拉近（約 2.45）；連打短暫晃動；打完 Screen KO 時再短暫拉近，之後回到當前視野。方向丟掉砸中小偷同樣播 Screen KO（見 `thiefsystem.md`）

#**行動裝置操作方式 (iOS/Android／網頁觸控)**
操作模式
虛擬搖桿 + 虛擬按鍵（LoL 手機式右手簇）。**預設關閉**。準備**系統工具**或營運**暫停選單**可開／關（`user://settings.cfg` → `[ui] virtual_stick`）。活躍輸入為實體手掣或鍵盤時自動隱藏。詳見 `inputmodes-vj.md`。

移動控制
左側虛擬搖桿（圓形；橫向畫面為準；跟 viewport 縮放，左右簇約各 ≤26% 寬）

動作控制
右側虛擬按鍵（跟 `inputmodes-vj.md` 附圖：大行動核 + 衛星 + 技1–5 斜弧）
- 大核：行動（同 A／J）
- 左：衝刺／跑（同 X／K）
- 上：取消／丟（同 B／;）
- 最上：奧義（同 U）
- 斜弧技1–技5：直放（技1＝中間技能；技2–5＝LB／RB／LT／RT）

觸控注意
- 左手搖桿與右手按鍵可同時按住（收銀／技能／奧義期間仍可用搖桿輸入方向；清潔期間搖桿用來轉清潔計）
- 指令模式時搖桿視為方向鍵，角色不移動。清潔、打擊期間角色也不移動，但搖桿／連按用途不同
- Autoload `InputMode` 分辨觸控／手掣／鍵盤三態

#**營運回合預設操作**

鍵盤、Xbox 手制、行動裝置虛擬鍵對應**同一套 InputMap 動作**（見檔首 action 表）。Xbox 的 X／Y／A／B **只是手制與虛擬鈕名稱**，不是鍵盤 WASD；邏輯層只認 `interact`／`dash`／`skill`／`cancel` 等。

##手制操作 (Xbox Layout)
- 移動
- - 左搖桿／十字鍵

- A: 行動 (與物件互動)
- X 輕放（約 0.18 秒內）: 衝刺
- X 長按: 奔跑（不會先衝一記）
- Y 短按: **直接施放技能1**
- Y 長按: 彈出技能選單。拉方向只預覽，放手 Y 才發動；沒拉方向就放手則發動中間技能1
- - 選單方向：上: 技能2　右: 技能3　下: 技能4　左: 技能5
- LB: 直接施放技能2
- RB: 直接施放技能3
- LT: 直接施放技能4（單邊；與 RT 同時按則改走奧義和弦，不施放）
- RT: 直接施放技能5（同上）
- 長按 LT+RT（約 0.18 秒）: 準備施放奧義（按住期間輸入方向指令；**兩邊都放手**取消）。Web：板機軸若與左搖桿別名（四軸手制）則忽略並鎖存；左搖桿偏轉較大時亦不信任軸上 LT/RT（避免深推／斜推誤觸奧義），改認 Standard Gamepad 按鈕 6／7
- B 在技能選單中: 關閉選單，不發動
- B 按下: 取消
- B 長按（約 0.2 秒進入瞄準）: 丟掉手上最上連續同 SKU 段。達門檻後仍按住可瞄準，**放手才掉出**；鎖移動但可用方向改面向。有方向則飛出約 5 身位並以**青色**顯示軌道／落點（免與暖色地板撞色），落地後才可再移動；軌道／落點擊中小偷 → Screen KO（贓物原地掉落）；否則可砸客人／落在同款／可接受貨架上直接補架（剩貨掉地）。生效中的**狙擊手**會改寫落點（優先序小偷 → 客人 → 貨架；見 `playeractiveskills.md`）。沒方向則掉腳邊。一次長按只丟最上一段。空手、暈眩、滑倒、打擊中不會丟
- **視圖鍵（View／Select）:** 營運中循環鏡頭視野（正常 → 稍遠 → 全地圖）；暫停開著時改由暫停選單「鏡頭」列操作

##行動裝置操作（虛擬鍵）
- 佈局見上／`inputmodes-vj.md`：大核行動、左衝刺、上取消、最上奧義、斜弧技1–5 直放
- 技1–5 短按即施放對應技能（唔再靠虛擬「技能選單」掣；鍵盤 L／手掣 Y 長按選單仍可用）
- 長按虛擬奧義鈕: 準備施放奧義（按住期間輸入方向；放手取消）
- 其餘行動／衝刺／取消／丟掉與 Xbox 面鈕相同語意

##鍵盤操作
- 移動
- - W:上
- - S:下
- - A:左
- - D:右

- J: 行動 (與物件互動)
- K 輕放（約 0.18 秒內）: 衝刺
- K 長按: 奔跑（不會先衝一記）
- V: 循環鏡頭視野（正常 → 稍遠 → 全地圖；同 Xbox 視圖鍵）
- L 短按: 彈出技能選單（不發動）。再按方向即發動該格；再按一次 L 發動中間技能1
- L 長按: 彈出技能選單。拉方向只預覽，放手 L 才發動；沒拉方向就放手則發動中間技能1
- - 上: 技能2　右: 技能3　下: 技能4　左: 技能5
- ; 在技能選單中: 關閉選單，不發動
- ; 按下: 取消（Backspace 同樣是取消）
- ; 長按（約 0.2 秒進入瞄準，放手掉出）: 丟掉手上最上連續同 SKU 段（瞄準鎖移動、可改方向、5 身位飛出、青色軌道；可砸小偷 KO／交付客人／同款貨架上架；狙擊手覆寫見 `playeractiveskills.md`）。與手制 B 長按相同
- 長按 U: 準備施放奧義技能（按住期間輸入 WASD；放手取消）

##指令模式（角色不移動）
以下期間方向輸入只作指令，不走路：
- 長按行動＋收銀機後方：收銀方向指令
- 長按行動＋補貨點：貨品清單上／下
- 技能選單（短按留下，或長按按住）：方向選技能，不走路
- 長按奧義：奧義方向指令

清潔（長按行動＋污物）：搖桿／`move_*` 轉清潔計，不當收銀方向鍵。
打擊（長按行動抓住小偷後，含離店途中的小偷）：連按 `interact` 扣血，方向不當指令。連打晃動、打完 Screen KO；詳見 `thiefsystem.md`。

準備回合**店舖設計**（見 `shopsetup.md`）：進頁先地圖焦點，方向移游標；短按 `interact` 拿起／放下；補貨架長按 `interact` 設預設 SKU；`cancel` 無持物時切清單焦點並先落尺寸列（左右改闊／長，再下到物品清單；再取消才返回）；持物中 `cancel` 還原原格或退回未放置；`rotate`（預設手制 X、鍵盤 K）轉向。

#**補貨點取貨操作**
- 面向補貨點**輕放**行動：立刻提取目前選中貨品 **1 件**
- 面向補貨點**長按**行動：彈出貨品清單（畫在最高層）
- - 方向 上／下 改選 SKU
- - **放手**行動確認該補貨點往後都拿此 SKU
- - B 或 ; 取消，維持原本選中
