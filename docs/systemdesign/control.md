#**操作設定**
- 此檔案包含操作設定
- Demo 實作範圍與試玩數值以 `docs/demo/` 各版本 scope 為準（v0.3 起已實作下列營運回合操作；清潔見 v0.4，打擊見 v0.5）
- **v1 活線工程：** `godot/game`。輸入以 Godot **InputMap action** 為準（Autoload `Controls`）。鍵盤／手制／觸控都對到同一套 action；下列鍵位是**預設綁定**，可在專案設定改鍵，不改玩法邏輯。
- **手制裝置：** 單機時 Xbox 預設綁定的 InputMap `device` 為 **-1（任何已連接手把）**；左搖桿輪詢走 `Input.get_connected_joypads()`，不寫死 device 0。Windows 常把 Xbox 編成 0 以外的裝置（XInput + DirectInput 雙重列舉、虛擬／幽靈手把佔 0），Mac 則多半就是 0。
- **本機雙人（M1）：** Seat0＝手把 **device 0**，Seat1＝手把 **device 1**。鍵盤可佔**尚未被手把綁定**的 seat；兩 seat 都已被手把佔用時鍵盤無效。詳見 `multiplayer.md` §11.4。
- 主要 action：`move_*`、`interact`、`cancel`、`dash`、`skill`（LB＝持貨揀選）、`bag_menu`（RB＝技能環）、`carry_menu`（面鍵 Y 備用）、`ult`、`bag_slot_*`（D-Pad／方向鍵＝道具）、`carry_prev`／`carry_next`（Y／I）、`skill_hot_1`–`5`；衝刺／跑＝面鍵 **X**／鍵盤 **Space**；奧義＝LT+RT／鍵盤 **K** 長按；準備店舖設計另有 `rotate`（鍵盤 **R**；prep 情境面鍵 Y）；補貨快捷 `restock_*`；鏡頭 `camera_view`（鍵盤 `V`、Xbox 視圖鍵）
- **營運移動：** 僅左搖桿＋鍵盤 **WASD**＋觸控 VJ。**方向鍵＝道具袋**（唔再綁 `move_*`）。
- **暫停選單：** 營運日 Esc／手把 Start 開關（見 `pausemenu.md`）。選單內移動／確定／取消走 `move_*`／`interact`／`cancel`（暫停可另輪詢搖桿／原生 D-Pad 導覽）
- **UI 文案：** 準備／暫停／HUD 等已遷字串表者走 Autoload `Loc`（`docs/alpha/i18n.md`），與鍵位無關
- 交叉顯示：[`player-context-ui.md`](player-context-ui.md)

#**Xbox ↔ Keyboard 對照（營運）**

| Xbox | Keyboard | Action |
| --- | --- | --- |
| 左搖桿 | WASD | 移動（開技能環／持貨揀選期間仍可） |
| A | H（另可 Enter） | 行動／互動 |
| B | J（另可 Backspace） | 取消／丟貨；技能環開時關環；**長按 LB 期間借用＝持貨焦點右** |
| X | Space | 輕放＝衝刺、長按＝奔跑；**長按 LB 期間借用＝持貨焦點左** |
| Y（面鍵） | U | **備用**（舊持貨環；營運唔再開環） |
| LB | —（鍵用 Y／I 切焦點） | **長按 ≥220ms**＝持貨五格揀選 |
| RB | —（鍵用 1–5 直放） | **長按 ≥220ms**＝技能環 |
| LT+RT | K | 長按＝奧義準備 |
| D-Pad 上／右／下／左 | ↑→↓← | 即用道具袋格 0–3 |
| — | Y／I | 持貨焦點左／右 |
| — | 1／2／3／4／5 | 技能環穴 1–5 直放（主動序） |
| View | V | 鏡頭視野 |
| Start | Esc | 暫停 |

注意：面鍵 **Y→U**；鍵盤字母 **Y／I＝持貨焦點**——唔同鍵。短按 LB／RB／面鍵 Y：**暫時備用**。

#**遊玩視點**
- 以俯瞰視角觀察商店
- 鏡頭預設追蹤玩家角色隨角色移動（全地圖模式除外）
- **本機雙人（M1，見 `multiplayer.md` §11）：** 鏡頭**永遠跟隨兩可控角色的中點**；不做焦點切換。全地圖仍鎖店中心。
- **線上（M2，見 `multiplayer.md` §12.5）：** 各機鏡頭跟隨**本機擁有且仍在場**的 seat 中點（僅一 seat 則跟該角色）；遠端他角用世界標記，不做分屏。全地圖仍鎖店中心。
- 三種可調視野（暫停選單循環，或營運中 `camera_view`：鍵盤 `V`／Xbox 視圖鍵）。寫入 `user://settings.cfg` → `[ui] camera_view`；改完立刻生效，跨營運日保留
- - **正常**（`normal`，預設）：Camera2D zoom **1.22**，跟隨玩家（雙人時為中點）
- - **稍遠**（`far`）：固定 zoom **0.95**，跟隨玩家（雙人時為中點），可見範圍略大於正常
- - **全地圖**（`overview`）：依當日店舖地板尺寸與 viewport 計算 zoom（約 8% 邊距），鏡頭**鎖在店中心**、不跟隨玩家
- HUD 與虛擬鍵不隨世界放大
- 施放技能／奧義時鏡頭會短暫再 ZOOM IN，然後回到**當前視野**基值
- 抓住小偷打擊時鏡頭再拉近（約 2.45）；連打短暫晃動；打完 Screen KO 時再短暫拉近，之後回到當前視野。方向丟掉砸中小偷同樣播 Screen KO（見 `thiefsystem.md`）

#**行動裝置操作方式 (iOS/Android／網頁觸控)**
操作模式
虛擬搖桿 + 虛擬按鍵（LoL 手機式右手簇）。**預設關閉**。準備**系統工具**或營運**暫停選單**可開／關（`user://settings.cfg` → `[ui] virtual_stick`）。活躍輸入為實體手掣或鍵盤時自動隱藏。詳見 `inputmodes-vj.md`。

移動控制
左側虛擬搖桿（圓形；橫向畫面為準；跟 viewport 縮放，左右簇約各 ≤26% 寬）

動作控制
右側虛擬按鍵（跟 `inputmodes-vj.md` 附圖：大行動核 + 衛星 + 技1–5 斜弧）
- 大核：行動（同 A／H）
- 左：衝刺／跑（同 X／Space）
- 上：取消／丟（同 B／J）
- 最上：奧義（同 K／LT+RT）
- 斜弧技1–技5：直放（觸控捷徑；對齊鍵盤 1–5）

觸控注意
- 左手搖桿與右手按鍵可同時按住（收銀／技能／奧義期間仍可用搖桿輸入方向；清潔期間搖桿用來轉清潔計）
- 指令模式時搖桿視為方向鍵，角色不移動。清潔、打擊期間角色也不移動，但搖桿／連按用途不同
- Autoload `InputMode` 分辨觸控／手掣／鍵盤三態
- **本輪 Ambient Peek 對齊以手掣／鍵盤為準**；觸控後補

#**營運回合預設操作**

鍵盤、Xbox 手制、行動裝置虛擬鍵對應**同一套 InputMap 動作**。Xbox 的 X／Y／A／B **只是手制名稱**；邏輯層只認 `interact`／`dash`／`skill`／`bag_menu`／`carry_menu`／`cancel`／`bag_slot_*` 等。

##肩鍵／Ambient（主路徑）

| 鍵 | 短按 | 長按（≥220ms） |
| --- | --- | --- |
| **LB** | 備用 | 持貨展開五格揀選（＋X／B 循環焦點） |
| **RB** | 備用 | 技能環（＋右搖桿瞄外圈即放） |

- **道具環／持貨環：廢主路徑**（顯示改角色旁斜十字／身下焦點；見 `player-context-ui.md`）
- 技能環開／持貨揀選期間：**左搖桿／WASD 可移動**（唔入指令鎖）
- 放開 LB／RB：收攏／關環；未施放則取消
- 奧義仍 LT+RT／K；**唔入技能環**

##手制操作 (Xbox Layout)
- 移動：**僅左搖桿**
- **D-Pad：** 即用道具袋（上／右／下／左＝格 0–3）
- A: 行動
- **X 輕放：** 衝刺；**X 長按：** 奔跑（約 0.12 秒門檻；起跑唔會先衝）；**長按 LB 時借用＝持貨焦點 −1**
- **Y（面鍵）：** 備用
- **LB 長按：** 持貨五格（中＝焦點）；放開收攏
- **RB 長按：** 技能環；右搖桿推向外圈即施放；B／中心／放開 RB＝取消
- LT 單邊：無
- RT 單邊：無（唔再 dash）
- 長按 LT+RT（約 0.18 秒）: 奧義準備（按住輸入方向；兩邊放手取消）。Web：板機軸別名安全見活線 `Controls`
- B: 取消；技能環開時關環；短按丟／長按瞄準丟；**長按 LB 時借用＝持貨焦點 ＋1**
- **視圖鍵：** 循環鏡頭視野

##行動裝置操作（虛擬鍵）
- 佈局見上／`inputmodes-vj.md`
- 技1–5 短按可直放（觸控捷徑）
- 長按虛擬奧義鈕: 奧義準備
- 行動／衝刺／取消語意同 Xbox A／X／B

##鍵盤操作
- 移動: **WASD**（方向鍵改綁道具）
- H: 行動
- Space 輕放／長按: 衝刺／奔跑
- **Y／I:** 持貨焦點左／右（短展開五格後 linger）
- **↑→↓←:** 即用道具袋
- **1–5:** 技能穴直放
- U: 備用（舊持貨環）
- K 長按: 奧義準備
- J: 取消／丟貨（語意同 B）
- V: 鏡頭視野

##指令模式（角色不移動）
以下期間方向輸入只作指令，不走路（左搖桿／WASD）：
- 長按行動＋收銀機後方：收銀方向指令
- 長按行動＋補貨點：貨品清單上／下
- 長按奧義：奧義方向指令
- （技能環／持貨揀選／道具即用**唔**鎖移動）

清潔（長按行動＋污物）：左搖桿／觸控 VJ／鍵盤 WASD 轉清潔計。  
打擊：連按 `interact`。  
上架 Circle／丟掉瞄準或投出飛行中：禁用道具袋。

準備回合**店舖設計**（見 `shopsetup.md`）：`rotate` 預設鍵盤 **R**；prep 情境面鍵 Y 亦可轉向（營運面鍵 Y＝備用，兩情境不重疊）。

#**補貨點取貨操作**
- 面向補貨點**輕放**行動：立刻提取目前選中貨品 **1 件**
- 面向補貨點**長按**行動：彈出貨品清單（畫在最高層）
- - 方向 上／下 改選 SKU
- - **放手**行動確認該補貨點往後都拿此 SKU
- - B 或 J 取消，維持原本選中
