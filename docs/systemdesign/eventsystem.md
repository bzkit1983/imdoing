# 本檔要定義什麼（之後再填）

| 槽位 | 說明 |
|------|------|
| 觸發來源 | 日循環相位、評價、隨機池、劇情章節（Beta） |
| 修飾器 | 流量／污物／小偷／價格／任務條件等短時修正 |
| 與任務關係 | 一次性事件任務 vs 期間限定可重覆 |
| 與劇情關係 | 章節事件 vs 日常營運事件；解鎖權威仍歸劇情／任務 |
| 活線邊界 | 預設 EA 不做事件 runtime；若章節內容必須用事件任務，須另作決議後才開 |
