#上架系統設定
- 此檔案包含上架系統設定

#**補貨點**
補貨點為商店物品
由店舖準備回合時經"採購"購買，所有購入的貨品能在補貨點提取
補貨點的貨品以一箱為單位
每箱包含4件貨品

#**補貨點類別**
不同補貨點類別可提取不同類型的貨品
初始類型
- 乾貨類
- 凍櫃類
- 冰櫃類

後續設計可新增貨品類型

#**補貨點取貨**
角色面向補貨點時用行動鍵取貨。執貨**沒有** Loading Circle，輕放即時完成。
每箱貨品預設有4件貨品
視覺效果角色會手持一箱該貼上貨品圖示的貨箱
動畫效果類似由補貨點吸入到角色，數量多時吸入特效更爽快。

#**補貨點改選貨品**
同一補貨點有多種 SKU 時：
- **輕放**行動鍵：立刻提取目前選中的貨品一箱
- **長按**行動鍵：彈出貨品清單（必須畫在畫面最高層，不被貨架／補貨點擋住）
- 清單開啟期間方向上／下改選（鍵盤 WASD、手制十字／搖桿、虛擬搖桿皆可）；角色不移動
- **放手**行動鍵確認選中，之後該補貨點記住此 SKU
- B 或鍵盤 ; 取消，維持原本選中、不執貨

鍵盤不再用單獨按鍵輪換 SKU；手制與行動裝置與鍵盤同一流程。

#**攜帶貨物**
根據角色STR值影響的負重值，能帶上更多貨品
攜帶貨物數量到負重值上限便不能再攜帶貨物.
負重值能透過發動技能直接提升
角色同時可取多種不同類型貨品

#**攜帶貨物清單**
角色身上有一個已攜帶貨物清單 (Queue), 清單以First In Last Out形式上貨
清單中最後的貨品才能用作上貨架
清單的實際數據儲存會按物品的最少單位一件一件排列
畫面有迷你攜帶貨物清單幫助玩家了解身上貨品順序
例子: 
補給拿貨次序為
1. 牛奶 1箱
2. 牛奶 1箱
3. 杯麵 1箱
9. 牛奶 1箱

畫面清單會以小圖示顯示:
牛奶 X 8
杯麵 X 4
牛奶 X 4

角色動畫圖會手持個4個一直疊起的貨箱.
1. 牛奶箱
2. 牛奶箱
3. 杯麵箱
4. 牛奶箱

#**貨架**
貨架為商店物品
貨架分為不同類別, 同一個貨架只能放置同類型貨品
根據貨架品質，越高品質能放置更多數量的同件貨品

#**貨品上架**
角色面向貨架時按行動鍵能補充貨物
如果角色身上沒有貨物時不能對貨架互動
如果貨架上為空架, 角色可補充身上貨物上架
如果貨架上已經有貨, 角色只能補充身上同樣貨物上架, 如不是同樣貨品會顯示叉交圖示不能上架
貨箱內貨品完全上架後會自動消失

#**貨品上架與攜帶貨物清單的互動**
如果角色持有多種貨物在身，在空架時只能補上清單最後貨品
如果清單中的貨品相同, 可以連續上架, 直到清單的物品不同為止.

#**上架行動時間**
上架行動時間根據角色AGI值而定。
角色AGI值越高上架時間越快。
動畫效果類似由角色噴射到貨架，數量多時噴出特效更爽快。
角色發動上架相關技能時有機會瞬間完成。
