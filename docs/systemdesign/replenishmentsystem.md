#上架系統設定
- 此檔案包含上架系統設定

#**補貨點**
補貨點為商店物品
由店舖準備回合時經"採購"購買，所有購入的貨品能在補貨點提取
補貨點的貨品以一箱為單位
每箱包含4件貨品
關店時貨架與地上未售件數會退回倉庫箱數（見 `storeoperationphase.md`），下回合可再從補貨點提取。

#**補貨點類別**
不同補貨點類別可提取不同類型的貨品
初始類型
- 乾貨類
- 凍櫃類
- 冰櫃類

後續設計可新增貨品類型

開始營業前，店舖內要已放置至少一組同類型的補貨架和貨架。乾貨補貨架配乾貨貨架、凍櫃配凍櫃、冰櫃配冰櫃，有其中一組就可以。只購入、還沒放到店舖設計圖上，不算。

#**補貨點取貨**
角色面向補貨點時用行動鍵取貨。執貨**沒有** Loading Circle，輕放即時完成。
每箱貨品預設有4件貨品
視覺效果角色會手持一箱該貼上貨品圖示的貨箱
動畫效果類似由補貨點吸入到角色，數量多時吸入特效更爽快。

#**補貨點改選貨品**
同一補貨點有多種 SKU 時：
- **輕放**行動鍵：立刻提取目前選中的貨品一箱
- **長按**行動鍵：彈出貨品清單（必須畫在畫面最高層，不被貨架／補貨點擋住）
- 清單開啟期間方向上／下改選（InputMap `move_*`：預設鍵盤 WASD、手制十字／搖桿、虛擬搖桿皆可）；角色不移動
- **放手**行動鍵確認選中，之後該補貨點記住此 SKU
- B 或鍵盤 ; 取消，維持原本選中、不執貨

鍵盤不再用單獨按鍵輪換 SKU；手制與行動裝置與鍵盤同一流程。

#**攜帶貨物**
負重以箱計算：負重 1 點＝1 箱（每箱 4 件）。
來自 STR 的箱數見 `playerstats.md`（STR 10＝3 箱，STR 50＝11 箱，再高也不加）。
「頂硬上」等技能直接加負重箱數，可超過 STR 50 的 11 箱。
空手或身上未滿負重即可再執貨；已達或超過當前上限便不能再取（不會因執貨而超重）。
頂硬上等加負重結束後，身上多出來的貨**不會掉落**，但移動會因超出當前上限而減速，直到上架後回到上限以內。
角色同時可取多種不同類型貨品

#**攜帶貨物清單（堆疊）**
角色身上是**堆疊**：後取的在最上層；**後取先上／先丟**（最上一段先上架或丟掉）。
清單按件儲存；畫面以連續 run 顯示（例如牛奶×8、杯麵×4、牛奶×4）。
例子（取貨順序由下到上）：
1. 牛奶 1 箱  
2. 牛奶 1 箱  
3. 杯麵 1 箱  
4. 牛奶 1 箱  

畫面：牛奶×8 → 杯麵×4 → 牛奶×4（最上）。  
角色手持四層貨箱，最上層＝下一次上架／丟掉的那段。

#**貨架**
貨架為商店物品
貨架分為不同類別, 同一個貨架只能放置同類型貨品
貨架的品質是不同款式。同一種類有 4、8、12、24 件四款，容量越大越貴。款式和價格見 `shopitem.md`。一箱 4 件，所以這四款分別盛 1、2、3、6 箱。

#**貨品上架**
角色面向貨架時按行動鍵補充貨物。上架 Loading Circle 畫在畫面最上層（不被貨架擋住）。
**短按**行動，貨架有貨時取 **1 件**進手持（1 件佔 1/4 箱；空位不足就不能拿）。見 `customerdelivery.md`。
**長按**才走上架 Circle。空手長按不能上架。
如果貨架上為空架, 角色可補充身上貨物上架
如果貨架上已經有貨, 角色只能補充身上同樣貨物上架, 如不是同樣貨品會顯示叉交圖示不能上架
貨箱內貨品完全上架後會自動消失

#**丟掉貨箱上架**
長按取消並以**方向發射**丟掉貨箱時（見 `playeraction.md`），命中優先：小偷 → 一般客人 → 可接受貨架（各取最近一個）。落到貨架時：
- 空架：同類別即可；已有貨：必須相同 SKU（與近身上架相同）
- 最多補**該箱件數**：`min(箱內件數, 貨架剩餘空位)`（活線命中半徑約 `Tuning.DROP_SHELF_HIT_RADIUS`）
- 箱內用完 → 貨箱消失；有剩餘 → 剩餘掉地（可撿）
- **不套用**上架速度／瞬間補貨；補貨時段也可丟掉上架
- 無方向的腳邊丟掉、或落地不在貨架上 → 整箱掉地，不上架
- 不走近身上架 Loading Circle（直接補架）

#**貨品上架與攜帶貨物清單的互動**
如果角色持有多種貨物在身，在空架時只能補上清單最後貨品
如果清單中的貨品相同, 可以連續上架, 直到清單的物品不同為止.

#**上架行動時間**
上架行動時間根據角色 AGI 值而定（AGI 10＝2 秒，AGI 50＝0.2 秒，線性；見 `playerstats.md`）。
角色 AGI 值越高上架時間越快（AGI 50 後不再因 AGI 加快）。
只加快移動的技能不改 AGI，因此不縮短上架時間。
上架／瞬間補貨類技能只改上架 Circle（縮短或略過），不改 AGI、不加快移動。
動畫效果類似由角色噴射到貨架，數量多時噴出特效更爽快。
