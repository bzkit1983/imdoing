#角色行動設定
- 此檔案包含角色行動設定

#**行動表**
以下為角色的行動動作表

| 行動|狀態|對象| 
| ------------- |:-------------:| -----:| 
|執貨|空手，或身上未滿負重|對補貨點| 
|上架|手持貨物|貨架|
|收錢|空手|普通收銀機（`cashier`；**不含**自助 `self_cashier`）|
|維修自助收銀|空手或持貨|運作值未滿的自助收銀機（`self_cashier`，運作值 < 100；見 `cashiersystem.md`）|
|清潔|空手或持貨|污物|
|打擊|空手或持貨|小偷（含離店途中，直至完全離場）；打擊中貨留在手上|
|丟掉|手持貨物|無固定對象。短按取消丟焦點 1 件（面向／方向）；長按約 0.2 秒進瞄準，STR 累升件數後放手丟出；直線約 15 身位、飛行約舊基準 ×0.66、飛行中迴轉、青色真實落點。可砸小偷（Screen KO）、交付一般客人、或補同款貨架。**狙擊手**覆寫見 `playeractiveskills.md`|
|傳送|空手或持貨（貨保留）|已配對的傳送門（`portal`；見 `shopitem.md`／`shopsetup.md`）|

#**可互動發光**
補貨時段與營運時段，角色面向並進入互動距離時，若現在按行動鍵會對那個對象做出實際動作，該對象會微微發光（暖色光暈，慢慢明暗）。同一時間只亮行動鍵會作用的那一個。

會亮：可抓的小偷（空手或持貨）、有貨可取或手上的貨放得上去的貨架、有可選貨品的補貨架、負重放得下的地上貨箱、可清的污物（空手或持貨）、已有客人到櫃的**普通**收銀機、**運作值未滿可維修的自助收銀機**、開店時段手上有貨且還能收貨的客人、**已配對且另一端仍在場的傳送門**。

不亮：對不到、背對、超出距離；空手對空貨架、普通收銀機前沒有到櫃的客人、運作值已滿的自助收銀機（無需玩家收銀／維修）、補貨架沒有可選貨品、負重不夠撿地上的箱；未配對／orphan 傳送門；多重影分身（不是可交付客人、不是可互動對象，見 `shadowclone.md`）。準備回合、提早關店詢問、技能選單、奧義瞄準、暈眩、滑倒、掉貨瞄準期間也不亮。

**互動優先（短按／長按選目標時，高→低）：** 可抓小偷 → 污物 → 可交付客人 → 可上架／取貨貨架 → 補貨點 → 就緒普通收銀機 → **可維修自助收銀（運作值 < 100）** → 地上貨箱 → 營運道具 → **傳送門**。傳送門偏低，避免擋主操作。**進行中的長按**（收銀指令／上架 Circle／清潔／補貨點選 SKU／自助維修 BAR 等）不會被路過的小偷搶走；放開行動鍵後才重新選目標。
#**行動動作**
角色對對象進行行動時, 會有動作完成時間.
根據行動性質, 以角色能力值決定完成時間（上架／清潔看 AGI，打擊看 STR；收銀改為方向指令串，INT 減指令次數並加親收營業額％，見 `cashiersystem.md`／`playerstats.md`）。
只加快移動的技能不改 AGI，因此不縮短上架 Circle 或清潔計。
上架時如果裝備了上架速度被動或瞬間補貨，完成上架時間會另外縮短或略過。

#**行動時間**
執貨: 沒有行動時間
上架: AGI 10＝2 秒 Circle，AGI 50＝0.2 秒，中間線性（見 `playerstats.md`）
清潔: 見 `cleaningsystem.md`。長按行動後轉搖桿填清潔計 0→100；AGI 越高每下動搖加得越多（等同 AGI 10 全力轉約 5 秒、AGI 50 約 1 秒）
收錢: 長按行動＋方向指令；**無 Loading Circle**；指令完成即入帳（INT／技能見 `cashiersystem.md`）。僅普通 `cashier`
維修自助收銀: 對運作值 < 100 的 `self_cashier` 按行動鍵進入七區 BAR（含中途保養；**客人付款中不可進**；維修中客人不可付）。再按行動鍵命中一區加運作值，未滿 100 則連續下一輪，直到修好或取消鍵離開。詳見 `cashiersystem.md`
打擊: 見 `thiefsystem.md`。長按抓住後連按行動鍵扣血量計（100→0）；連打鏡頭晃動；打完 Screen KO 打飛小偷，贓物近距散落（可撿、不計被偷）。5 秒內打完，否則被撞開倒地 5 秒；失敗後小偷帶贓走離，途中仍可再抓／衝刺／方向丟掉砸中，走到出口才計被偷並彈「你已經被偷了！」。另：手持貨箱時可用方向丟掉直接砸中小偷（算打擊成功；贓物原地掉落）

#**行動動作案例**
上架長按行動會出現 Loading Circle；填滿才完成，放手重置。**一次長按上一輪**：空架上**焦點** SKU；已有貨的架上手上同款（不必焦點對齊）。Circle 完成後若仍按住行動鍵，只算未放手，不會立刻再開 Circle（要再上就放開再按）。
**收銀沒有 Loading Circle**：長按維持指令模式，打完方向串即入帳；放手重置指令串。
Loading Circle（上架用）畫在畫面最上層（viewport CanvasLayer；不被貨架等店面物件擋住）。
上架可在移動中起動；Circle 進行中角色不會繼續移動。
清潔、打擊不是這種 Circle：清潔要長按並轉搖桿填清潔計（持貨亦可，貨留手上）；打擊要長按抓住後連按扣血（持貨亦可，貨留手上）。
**清潔期間隱藏黃色 Loading Circle**，只顯示污物上的藍色清潔計＋迷你搖桿（見 `cleaningsystem.md`）。
**清潔**可邊走邊起動；長按開始填計後進行中鎖移動。打擊同：起手可走，抓住後不移動。詳見 `cleaningsystem.md`、`thiefsystem.md`。

#**行動指令**
對特定對象行動時要輸入指令才能完成行動
清潔改為長按行動＋持續轉動搖桿（迷你搖桿圖示在污物上方），不是收銀那種方向指令串。詳見 `cleaningsystem.md`。
打擊改為抓住後連按行動鍵扣血，不是收銀那種方向指令串。詳見 `thiefsystem.md`。
需要行動指令的動作:
- 收錢（普通收銀機方向串）
- 維修自助收銀（七區 BAR 遊標；見 `cashiersystem.md`）

補貨點**改選 SKU** 也用長按行動＋方向（上／下），但那是清單選擇，不是收銀那種隨機指令串。輕放行動仍是即時執貨。詳見 `replenishmentsystem.md`。

#**丟掉貨品**
拿錯貨、貨架又放不下時，用取消鍵丟掉手上**焦點 SKU**（清污物／抓小偷不必先丟貨）。**無腳邊丟**。
- 手制與虛擬鍵：B；鍵盤：;
- **短按：** 丟焦點 **1** 件（**投籃高手**＝最多 2；見 `playeractiveskills.md`）。有方向（左搖桿／WASD／VJ；不含 D-PAD）則往該向；**無方向則按當前面向**。直線約 **15** 身位、飛行速度為舊基準 ×**0.66**（`DROP_FLIGHT_SPEED_FACTOR`）。選貨／技能選單／奧義／進行中行動時短按仍只取消（既有吞取消例外）。**移動中短丟**會短暫停步約 **0.16** 秒（`Tuning.DROP_TOSS_MOVE_PAUSE_SEC`），避免角色追上飛出貨品；站立短丟不停步；飛行途中其餘時間仍可走
- **長按：** 約 0.2 秒進入掉貨瞄準（`Tuning.DROP_HOLD_SEC`）；進瞄準時 `n=1`，之後依 STR 累升（`drop_charge_per_sec = 2 + min(STR,50)/5`，上限＝焦點持有數；見 `playerstats.md`）。**放手才丟出 n 件**。落點旁顯示焦點 icon×n
- **掉貨準備：** 長按進入瞄準時**鎖移動**；左搖桿／WASD 改面向與丟出方向（不含 D-PAD）；預設方向＝當前面向。青色軌道畫到**真實落點**（途中牆／不可收架截斷；可收架可提示會補架）。**放手貨飛出後短暫停步**（同短丟 `DROP_TOSS_MOVE_PAUSE_SEC`），再恢復移動（不鎖到落地）。期間禁用道具袋（`opsitems.md`）。長按飛行中不可再開長按丟；短丟 1 件可連續
- **飛行：** 直線無拋物線；紙箱＋面貼飛行中迴轉（約 2 圈）；途中撞牆／補貨架／收銀機／其他角色 → 擊中點**掉地**；途中撞貨架 → **可收則補架（不落地）**，不可收則掉地
- **多目標（普通丟掉）：** 軌道／落點同一時間只處理**一種**命中——最近一名小偷 → 仍要這款的一般客人 → 可接受貨架 →（都沒有才）拒收客人／多重影分身。拒收客人不再搶走可上架命中。見 `shadowclone.md`。
- **狙擊手（有方向投出覆寫）：** 生效中的狙擊手把有方向投出（含面向丟）**自動改飛向技能目標**。三招同時生效優先序：**小偷 → 客人 → 貨架**。見 `playeractiveskills.md`
- **丟掉砸小偷：** 擊中仍在場的小偷（含離店途中）→ Screen KO；贓物原地掉落；**算抓住**。詳見 `thiefsystem.md`
- **丟掉砸一般客人：**
  - 丟出 SKU **在**該客人購物清單 → 盡量把需要的件數加入其已取貨；剩件掉地；每交對 1 件不滿 **−15**（最低 0）；頭頂「謝謝！」；若因此**清單清空**→立刻去收銀機排隊付款。視覺：SKU 圖示＋Tick（`ops-sku-icon-ui.md`）
  - SKU **不在**清單 → 整次丟出掉地；不满 **+15**；頭頂「不想要這貨品！」。視覺：SKU 圖示＋交叉（同上）
  - 只交對一部分：只套用每件 −15，不再另外 +15
- **親手交付與貨架單件**見 `customerdelivery.md`（交付／強塞仍**整手可匹配**，不限焦點）。短按行動：小偷 → 貨架取 1 件。長按行動：小偷 → 污物 → 客人 → 可上架貨架（空架上焦點；有貨架上手上同款）
- **丟掉上架：** 未砸中人時，落點／途中擊中可接受該 SKU 的貨架 → 最多補**本次丟出件數**（`min(丟出, 空位)`）；剩件掉地。不套用近身上架速度技能；不走近身上架 Circle
- 地上貨堆只有**玩家**可撿；**攝石人**可拆堆。見 `playeractiveskills.md`
- 空手時長按會提示手上沒有貨。暈眩、滑倒、打擊中不能丟

#**傳送門**
- Catalog／成對放置見 `shopitem.md`、`shopsetup.md`。互動 kind：`portal`
- **誰可用：** 僅玩家 seat 角色。店員、多重影分身、Dark Side 臨時工、客人、小偷皆不可
- **時段：** 補貨時段與營運時段皆可
- **操作：** 對準已配對且發光的傳送門，**短按行動鍵**啟動。持貨可傳（貨保留）
- **抑制啟動：** 上架 Circle／清潔／收銀指令／丟掉瞄準／打擊／暈眩／滑倒／技能選單／奧義瞄準／暫停／提早關店對話中 → 不可啟動
- **演出時長：** 約 **1.0 秒** 鎖移動與互動：入口粒子＋BEAM UP → **鏡頭立刻跳到出口** → BEAM DOWN 出現。無額外 CD（動畫本身互斥）；結束後可立刻再傳
- **落地：** 出口前方站位（依該端 `rot`）。若站位被傢俬／角色堵住 → **強制擠到最近可行走格**（不取消、不彈失敗）
- **同門序列化：** 同一入口端若多名玩家幾乎同時短按 → 門側佇列／鎖；一人完整 BEAM 完才受理下一人（不可同幀並行）。L 類 `InteractLock` 期間鎖該端（見 `multiplayer.md`）
- **鏡頭：** 跟隨目標立刻跳出口再播到達。若當下是全地圖 `overview`：到達時**強制切回跟隨視野約 1 秒**播到達，再恢復玩家原選視野（含 overview）。本機雙人中點鏡頭會隨傳送 seat 跳一次（可接受）
- **音效：** `sfx_portal_up`／`sfx_portal_down`（`soundeffects.md`）

收銀與奧義的方向圖示顯示在角色頭頂。
