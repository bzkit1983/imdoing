# Imdoing 小遊戲設計原則

**一局三至五分鐘。玩家玩完應該會記得一個笑位，最好仲想講畀人聽。**

## 1. 一局三至五分鐘

由入場到結算計，包含必要對白同教學。開頭畀玩家好快試到核心操作，中段加一兩次變化，尾段用反轉、挑戰或笑位收尾。未夠三分鐘，就加一個值得玩嘅變化，避免單靠拉長倒數或重複同一個操作湊時數。重試可以跳過睇過嘅開場。

## 2. 笑位最好由玩家親手觸發

每款小遊戲至少設計一個玩家可以**做出嚟**嘅笑位：畀假台階呃到、追問到騙子自己漏口風，或者用對手嘅招數反過來贏佢。結算可以補多一句對白，核心笑位應該喺遊玩當中已經發生。

## 3. 致敬做到「識梗更好笑，唔識都識玩」

優先從舊 Game、電影、歷史趣事或 meme 揀一個合適嘅參考。借用節奏、構圖、情境或包袱，再放入 Imdoing 嘅超市世界重新演繹。例如將街機格鬥嘅對峙構圖變成兩個人隔枱鬥食包。角色、台詞、美術同聲音用原創演繹，參考亦唔應該成為過關必備知識。

## 4. 對玩家有少少惡意，畀佢翻身

可以呃玩家一次，但玩家中伏後要睇得明**自己點解中招，下次可以點反應**。Dasher 可以每局抽真假台階同隱形磚位置，撞過嘅磚就喺同一局現形，令下一次有得避。隨機可以改變陷阱位置、角色反應同局勢。每個抽到嘅組合都要有解，失手後有短重試、檢查點或補救機會。對話遊戲可以用角色突然轉口達到同樣效果。

## 5. 試玩先決定值唔值得做大

每份新設計先寫清楚**玩家主要做咩、最想玩家笑邊一下、會點捉弄佢、佢點翻身**。先做最短原型驗證核心笑位，再擴成完整三至五分鐘。試玩時問：

- 唔識典故嘅玩家，能唔能夠自己開始玩？
- 玩完後，佢主動提起邊一幕？有冇想再玩一次？
- 中伏後，佢係想「下次我識避」，定係覺得點玩都冇用？

新作同大改版用呢套原則評審，現有短小遊戲按需要逐款再評估。
