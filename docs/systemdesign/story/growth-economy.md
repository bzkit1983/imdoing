# 1. 經濟哲學

- 前段高容錯毛利 → 中段低週轉／高成本 → 後段高賣價但損耗／頭目波動大。
- 損耗、失竊、壞掉貨**不入營收**（對齊 `ecosystem.md`）。
- 解鎖資格 ≠ 擁有：任務發「可開發／可購規模」後，仍付開發費／擴店費。
- 選章不打亂經濟曲線：規模與日營收帶跟 **slot 深度**，不跟「先選哪個主題」。

# 5. 通用貨品性狀 schema（草案）

## 5.1 形狀

```text
SkuTrait {
  trait_id: String
  params: Dictionary   # 例 spoil_after_unshelved_sec: float
}

SkuDef.traits: Array[SkuTrait]          # SKU 預設
ThemeModifier.trait_overrides: ...      # 主題級（舊稱章級）
EventModifier.trait_overrides: ...      # 事件級（當日或事件期間）
```

**解析優先序（高蓋低）：** 事件覆寫 ＞ 主題覆寫 ＞ SKU 預設。

覆寫可：改參數、`disable: true` 關閉該性狀、或替換 `trait_id`。

## 5.2 首批性狀

| trait_id | 參數 | 預設用途 |
|----------|------|----------|
| `spoil_unshelved` | `spoil_after_unshelved_sec` | 離架（手上／地上／交付途中）逾時→壞掉，不入營收 |
| `spoil_on_shelf` | `shelf_life_sec`（可選） | 架上亦限時（後段才用） |
| `fragile` | `break_on_dash_pct` | 衝刺持貨有機率損毀 |
| `heat_before_sell` | — | 需微波／加工才可售（後補系統） |
| `craft_only` | — | 禁採購；僅配方產出（熟食 `onigiri`／`yakimochi`／`nigiri`） |

凍櫃／冰櫃類 SKU **預設**掛 `spoil_unshelved`（冰櫃秒數更短，例凍櫃 45s、冰櫃 25s——實測調）。

## 5.3 主題／事件覆寫例

| 情境 | 覆寫 |
|------|------|
| `theme_climate`「冰天雪地」 | 主題修飾：所有 `spoil_unshelved` → `disable: true`（或秒數 ×10） |
| 夏日熱浪事件 | 事件：凍飲需求↑；`spoil_unshelved` 秒數 ×0.5 |
| 電力故障事件 | 事件：架上冷藏亦開始走 `spoil_on_shelf` |

# 6. 傢俬／開發／頭目資金

## 6.1 傢俬價（建議帶，相對舊表微調）

維持「容量越大越貴」比例思路；絕對值隨中後期營收上修。詳細件價落地時改 `shopitem.md`。

## 6.2 頭目任務資金獎勵（首次；不含當日營業額）

| 鍵（slot 深度／破局；可選主題頭目跟**當前 slot** 量級） | 頭目資金獎勵 |
|----|-------------:|
| `prologue` | 2000 |
| `chapter_01` | 1,000 |
| `chapter_02`／`theme_break` | 1,500 |
| 第3槽（任一主題） | 2,000 |
| 第4槽 | 2,500 |
| 第5槽 | 3,500 |
| 第6槽 | 4,500 |
| 第7槽 | 6,000 |
| 第8槽 | 7,500 |
| `finale` | 12,000 |

可選主題**首次**通關另可發主題專屬小額／道具；大額資金帶跟槽深，避免先選某主題扭曲經濟。

頭目日客流／壓力倍率建議：前 ×1.2 → 終 ×2.0–2.5（行為異常另加）；與資金獎勵分開計。
