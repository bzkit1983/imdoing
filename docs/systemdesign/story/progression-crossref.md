# 3. 遊戲進程對照（無數字版）

```text
序章          教學＋罐頭／零食＋凍飲／牛奶入門＋凍櫃教學＋持有資金三段達標＋序章頭目
  ↓
第1章         營運實踐、擴店、增收銀、杯麵／汽水等延續→約六款、兩店員、麻煩 LV1、頭目
  ↓
第2章         theme_break 破局；導入主題元素雛形；章末打開多元宇宙／選主題
  ↓
選主題循環    自六主題選一 → 填 slot 3…8 → 主題主線＋頭目 → 解鎖持久
  （可回訪已完成主題補任務／事件）
  ↓（六主題全清）
終章          大事任務鏈 → 最終頭目（約 LV60）
  ↓
後日談        自由營運、回訪主題、重玩性（LV61–99）
```

與舊「第2–8章各鎖死一個世界」差異：中段世界順序由玩家選擇；解鎖跟主題，節奏跟槽深度。

## 6.1 失敗擋推進 UX（已拍）

劇情任務失敗 → 不能 `advance_story`（不是 Game Over）。分流：

| 情境 | 方案 | 流程 |
|------|------|------|
| **日常劇情日** | **A 軟擋** | 關店結算照常 → 回準備 → 可再開店／接事件；同一劇情任務可跨日重試；**只擋進下一節／槽／選章** |
| **頭目日** | **D → C** | 失敗 → **失敗演出** → **回準備** → **再挑戰同一頭目節點**；通過前不推進 |

- `story_blocked`：擋推進中為 true
- 懲罰表、失敗演出長度：**待主題詳設／報酬表**

方案名詞對照：A 軟擋／B 當日重試／C 回準備再挑戰／D 敘事失敗態。
