# 概念（框架）

最終章完結後進入後日談。主線已結束，**無擋推進的主線劇情**。

玩家可：

1. **繼續營運** — 提升等級與賺錢（目標帶 **LV61–99**）
2. **回訪舊章** — 回到已通關章節的世界，完成未清任務／挑戰
3. **重玩性內容** — 輪換規則、隱藏解鎖、可選週期頭目等（後補）

# 推進與結束

| 項目 | 說明 |
|------|------|
| 進入條件 | `finale` 最終頭目通關 |
| 結束條件 | 無強制結束；滿級 99 為成長收束而非劇情完結 |
| 失敗擋推進 | 不適用於主線；可選挑戰可有自身失敗規則 |
