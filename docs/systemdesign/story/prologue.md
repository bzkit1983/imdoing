# 概念（框架）

序章＝**新手教學＋首段順利營運**。

- 不計劇本內容時：以劇情任務帶玩家一步步完成包裝教學式操作、基本商店設置與營運
- 另有**小型事件任務**解鎖基本類型的**初階技能**（具體技能 id 待技能分析）
- 教學系統（[`../tutorial.md`](../tutorial.md)）與序章的合併／並行關係：見開放問題（[`progression-crossref.md`](progression-crossref.md)）

# 主線推進條件（形狀，數字待分析）

推進序章的主要劇情任務方向（皆為條件**類型**，閾值不寫死）：

| 方向 | 說明 |
|------|------|
| 資金達標 | 累計資金達到指定金額 |
| 總評價達標 | 商店評價達到指定數目（見 `ratingsystem.md`） |
| 乾貨開發 | 按角色等級／章節旗標，分別開發到**三種乾貨類貨品** |
| 章末頭目 | 序章頭目戰（教學尖峰營運日） |

| 槽位 | 開檔內容 | 待補 |
