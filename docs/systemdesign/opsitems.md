# 營運道具（道具袋）

- 此檔定義營運回合地上生成的**道具**與每 seat **道具袋**
- 交叉：`control.md`（D-PAD／鍵盤 1–4）、`storeoperationphase.md`、`ratingsystem.md`、`cleaningsystem.md`、`thiefsystem.md`、`customer.md`／`playeractiveskills.md`（安撫對象）、`multiplayer.md`、`playeraction.md`
- 內部 id 前綴：`ops_item`（勿與 `shopitem.md` 傢俬、SKU `inventory` 混淆）
- 玩家字串：`data.csv`（`ops_item.<id>.name`／`.blurb`）、HUD／提示見 `strings.csv`

# 定義

- **道具**：僅在**營運回合**（基值＝開店段 `open`）生成於地上的消耗品；走近以**行動鍵短按**拾起，放入該 seat 的**道具袋**
- **道具袋**：每 seat 獨立；最多 **4** 格。格子對應十字 HUD：上／右／下／左
- 道具**不佔**手持負重、不進倉庫／貨架、不跨日（日結清空袋內與地上未撿）

# 功能解鎖

- **劇情模式：** 起始可無道具袋；以解決事件／章節任務逐步解鎖格數，最多 4。具體進度 BETA 劇情再定
- **現測試版本：** 4 格全開

# 介面

- **主路徑：** 長按 **X**（鍵盤 **I**）打開圍角色**道具圓盤**（中心 ❌ 取消；外圈上／左／右／下＝袋格）。見 [`player-context-ui.md`](player-context-ui.md)
- 螢幕常駐十字 HUD：**不再作為主顯示**
- **觸控測試版：** 之後對齊長按開盤

# 操作

見 `control.md` 營運道具段。摘要：

| 裝置 | 使用 |
| --- | --- |
| Xbox | **長按 X** → 道具圓盤；左搖桿揀；外圈放手使用；中心 ❌／B 取消 |
| 鍵盤 | **長按 I** → 同上 |
| D-PAD／1–4 | **暫非主路徑** |
| 觸控 | 本輪未對齊 |

- **Mode-steal：** 技能／道具圓盤／奧義準備／收銀指令／補貨清單開啟時，D-PAD 暫借給該模式
- **抑制使用：** 打擊、清潔、上架 Circle、丟掉瞄準／投出飛行中、暫停／準備／教學 modal／提早關店對話
- 空格或未解鎖格：外圈可高亮但放手無效
- 鍵盤 **1–3** 在補貨快捷會生效時優先給 `restock_slot_*`

# 出場與生成

- **劇情：** 指定章節後登場；每種道具登場時機 BETA 再定
- **測試版：** 三種基本道具皆可生成
- **基值：** 一個營業回合（`open`）約生成 **4–6** 次；Host-only；與污物／小偷 spawn 並列世界時鐘
- 特定章節／事件可覆蓋生成規則（之後接）
- 生成在店內可行走近的地面；**閃閃發光**提示拾起
- **走近辨認：** 玩家進入約互動距離時，道具上方彈出**道具名稱**（locale）；離開後淡出。HUD 對準時亦可顯示名稱
- 拾起：新 interactable `kind`＝`ops_item`；短按行動；優先序寫死以免與地上貨箱／污物搶光（建議緊鄰或略先於 `drop`）
- **滿袋：** 不能拾起；短提示（不自動替換）

# 多人

- 地上道具＝共享世界實體（Host 生成／銷毀；InteractLock）
- 道具袋＝**per-seat**（同手持／技能 CD）
- 拾起／使用走 Host Intent；Client 不本地刪世界代理人

# 道具列表（基本 3 種）

日後可持續新增；本檔為 catalog 來源。

## 安慰炸彈

- 程式 id: `comfort_bomb`
- 用途：使用後全店所有**尚未離店**客人的不滿度完全清零
- 對象規則**對齊安撫**：已達上限、正在離開商店的客人不受影響；小偷、Dark Side 臨時員工、多重影分身不是對象
- 評價：減不滿**不另加減**營運點（同安撫）；可間接避免 N1
- 視覺：掉出安慰炸彈 → 全畫面閃光；受影響客人頭頂開心情緒圖示

## 清潔炸彈

- 程式 id: `clean_bomb`
- 用途：使用後全店所有污物清除
- 評價／XP：**每團**結算同手動／掃地僧 `note_clean`（P4＋清潔 XP），掛使用玩家 seat
- 視覺：掉出清潔炸彈 → 全畫面閃光；污物煙霧並消失

## 壞人炸彈

- 程式 id: `villain_bomb`
- 用途：使用後全店所有活躍壞人（小偷）趕走
- 評價／XP：**每名**走 `record_caught`（P3＋抓賊 XP），掛使用玩家 seat（方法標記可為 `ops_item`）
- 視覺：掉出壞人炸彈 → 全畫面閃光；小偷被炸飛離場（贓物處理對齊既有 KO／趕走路徑）

# 測試版備註

- 4 格全開；生成基值 4–6／`open`；三種皆可刷
- 數值偏強時可另開權重表，不改本檔操作語意
