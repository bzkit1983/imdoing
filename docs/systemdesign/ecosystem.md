#生態系統設定
- 此檔案包含生態系統設定

#**生態系統**
生態系統為整個遊戲的進度集合
生態系統包含以下元素:
- 資金
- 經驗值
- 劇情進度
- 事件進度
- 玩家角色進度
- 店舖進度
- 店員狀態
- 貨品狀態
- 店舖物品狀態
- 店舖規模
- 店舖設計圖

#資金
- 用作支付購入商店物品
- 用作採購貨品入庫
- 用作開發新貨品
- 用作招聘員工
- 主要來源由營運回合結束後獲得。關店時把當日營業額加入資金。被偷金額不入營業額，也不入資金
- 當日營業額低於當日採購支出時，結算標為虧損。採購支出只計當日買入倉庫的貨，開發費、傢俬和工資不算。遊戲不因此結束

#經驗值
- 角色經驗值用作升級用
- 記錄當前經驗值
- 記錄下次升級所需經驗值
- 經驗值獲得途徑
- - 關店 +100
- - 每成功收銀 +2
- - 每抓住小偷 +10
- - 每成功清潔 +5
- 與資金分開計算

#劇情進度
商店會有劇情進度,有表單記錄遊戲進度
- 現在劇情進度
- 已完成劇情

#事件進度
商店會有事件發生,有表單記錄事件詳情
- 現在發生中的事件
- 事件達成度

#玩家角色進度
每個商店只有一位玩家角色登錄
商店記錄玩家角色所有狀態
- 等級
- 能力值
- 已學習技能
- 正在裝備的技能
營運回合開始時以玩家角色進度進行

#店舖進度
- 店舖的進度用作控制在何階段開放各種功能
- 達成條件以開放新功能
- 店舖進度詳見店舖進度設定

#貨品狀態
- 記錄已開發貨品的狀態
- 記錄已採購貨品在庫狀態

#店員狀態
- 記錄已招募店員狀態

#商店物品狀態
- 記錄已購入商店物品狀態

#店舖規模
- 記錄當前店舖尺寸大小的等級
- 店舖規模反映總面積, 每升一級便會加大可用尺寸
- 玩家能在店舖設計圖自行設定店舖的長和闊度

#店舖設計圖
- 記錄店舖設計圖
- 記錄各商店物品的配置情況
- - 位置
- - 方向
