#生態系統設定
- 此檔案包含生態系統設定

#**生態系統**
生態系統為整個遊戲的進度集合
生態系統包含以下元素:
- 資金
- 經驗值
- 營運回合評價／商店評價（見 `ratingsystem.md`）
- 整體難度（見 `difficulty.md`）
- 劇情進度
- 事件進度
- 玩家角色進度
- 店舖進度
- 店員狀態
- 貨品狀態
- 店舖物品狀態
- 店舖規模
- 店舖設計圖

#資金
- 起始資金 $2500。LV1 開張約用 $1800（收銀機 $1000、乾貨補貨架 $500、乾貨架 12 件 $100、罐頭 20 箱 $200），餘額可再進貨，不夠把店一次買滿
- 用作支付購入商店物品
- 用作採購貨品入庫
- 用作開發新貨品
- 用作招聘員工
- 主要來源由營運回合結束後獲得。關店時把當日營業額加入資金。被偷金額不入營業額，也不入資金
- 當日營業額低於當日採購支出時，結算標為虧損。採購支出只計當日買入倉庫的貨，開發費、傢俬和工資不算。遊戲不因此結束
- 營運中成功收銀時，在收銀者頭頂綠字飄出當筆營業額（`$+N`）；實際 `state.money` 仍於關店入帳

#經驗值
- 角色經驗值用作升級用
- 記錄當前經驗值
- 記錄下次升級所需經驗值
- 經驗值獲得途徑。經驗只會增加，不會減少
- **活線已接**產品日結帶與升級曲線：[`story/growth-character.md`](story/growth-character.md) §2–3；`session/xp_rules.gd`。尚無章節 id 時以等級帶代理。例（LV1–18）：關店 +80／收銀 +3／麻煩 +12／賊 +15／清潔 +6；更高帶見該文。
- 收銀計入：玩家、正式店員、Dark Side 臨時收銀、多重影分身分身；麻煩客人見 `elitecustomer.md`；抓賊含近身連打／丟箱／衝刺撞飛。
- 劇情／事件／頭目任務可另發 XP（個別報酬；頭目大額見成長分析）。見 `storysystem.md`、`playerlevel.md`
- 與資金分開計算
- 營運中上述收銀／抓小偷／清潔事件當下，在完成動作者頭頂綠字預告 `+N XP`（正式寫入仍在關店結算；coop 平分規則不變）

#玩家角色進度
每個商店只有一位**主**玩家角色登錄（店主）。
商店記錄店主角色所有狀態
- 等級
- 能力值
- 已學習技能
- 正在裝備的技能
營運回合開始時以玩家角色進度進行

**本機雙人（M1）：** 可另載訪客角色槽（只含角色進度、無店舖）。同店最多兩可控角色；結算與槽規則見 `multiplayer.md` §11。線上訪客有自己店時的資金規則見同檔 §5.4／§10。

#店舖進度
- 店舖的進度用作控制在何階段開放各種功能
- 達成條件以開放新功能
- 店舖進度詳見店舖進度設定
- **產品方向：** 功能解鎖由**劇情／事件任務**發放（等級不解鎖；可作任務條件）；**不用**商店評價／營運點支付解鎖。過渡等級表見 `shopprogress.md`（作廢中）；規模／貨品建議見 [`story/growth-economy.md`](story/growth-economy.md)
- 任務條件：`tasksystem.md`；報酬表細節可標 Beta（`docs/beta/design.md`）

#營運回合評價與商店評價
- 定義、行為加減、評級帶、30 日歷史、難度建議觸發：見 `ratingsystem.md`
- 營運點每次開店重設為 50；日結只依最終營運點定評級 −3…+3，再加減商店評價（下限 0）
- 評價不作貨幣；主要作事件／劇情／成就等達成條件；亦可作任務 metric（見 `tasksystem.md`）
- 正式任務報酬可改 `shop_rating`／發 XP 等（細節 Beta，見 `docs/beta/design.md`）
- Host 店才累積商店評價；訪客另計「支援別店評價」（`multiplayer.md`）

#任務進度
- 營運／事件／劇情任務共用條件語意：見 `tasksystem.md`
- 持久欄至少含 `day_index`、per-seat 進行中任務（含提早關店仍 +1 日）
- 測試內容：`taskcontent-ops-test.md`

#店舖規模
- 記錄當前店舖尺寸大小的等級（活線 **S1–S6**）
- 店舖規模反映**總面積上限**（非邊長平方硬綁）；擴店**只收資金**（等級門已拿掉；任務解鎖之後再加）
- 面積／擴店費／雇員上限見 [`story/growth-economy.md`](story/growth-economy.md) §3、`shopsetup.md`
- 玩家能在店舖設計圖自行設定店舖的長和闊度（`w*h ≤ area_cap`、每邊 ≥8）
