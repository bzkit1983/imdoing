#營運準備設定
- 此檔案包含營運準備設定
- 工程活線：`godot/game`。版控見 `docs/versioning.md`。存檔見 `docs/systemdesign/savesystem.md`


- 營運準備選單
開店前, 關店後進入營運準備選單。操作沿用 `docs/systemdesign/control.md` 的選單鍵（InputMap：`move_*`／`interact`／`cancel`；店舖設計轉向用 `rotate`）。實作：殼層 `godot/game/scenes/prep_menu.tscn`，分頁填充分散在 `godot/game/scripts/prep/`（協調者仍為 `prep_menu.gd`）。可見文案走 `Loc`（`prep.*`；見 `docs/alpha/i18n.md`）。主畫面為**圖塊化分類**（佔位圖示可之後換 `art/ui/prep/<id>.png`），中間分類格可垂直捲動；**難度**與「開始營運」固定在底部不重疊。子目錄為大觸控列。畫面分頁：

1. 角色整備（`hub_char`）
- 角色能力
- 裝備技能（五組自訂組合，準備時選用並可改未選用的組。入口不顯示 COST；見 `customizedskillset.md`）。Dark Side、多重影分身在該組可選 LV1／2／3（沒選預設 LV3；見 `darkside.md`、`shadowclone.md`）
- 外觀調整（已開放：造型＋色調＋idle 預覽；見 [`appearance.md`](appearance.md)）
2. 貨品管理（`hub_goods`）
- 開發商品
- 採購貨品
- 設定可售貨品（已開發清單切換可售／不可售；至少保留一項可售；開發後預設可售。不可售者不進客人／小偷購物清單，也不能採購或補貨選用；見 `customer.md`、`procurement.md`）
3. 店舖管理（`hub_shop`）
- 購入商店物品
- 擴張店舖
- 店舖設計
3b. **分店**（設計；清完第一個可選主題後解鎖；見 [`branchstore.md`](branchstore.md)）
- 建議 home 獨立圖塊（或掛 `hub_shop` 下）
- 選非本店的已開主題店 → 在店貨品採購、售賣開關、營運方針、店長／四崗位（收銀／補貨／清潔／保安；可空，最少店長）
- 採購與自動補貨扣**共用資金**；人力與本店出勤／派駐**互斥**
4. 員工管理（進店員 hub；下設分頁）
- **一般店員**：召募、崗位配置、改派收銀機、解僱（見 `clerksystem.md`；本店雇員；各主題店各自招聘）
- **精英店員**：已解鎖列表；詳情（背景／等級／能力／固有技能／可分配崗位）、出勤、多崗位指派、金錢升級（見 `eliteclerk.md`；不可招聘）。已派駐分店者不可本店出勤（互斥校驗）
5. 系統工具（`hub_sys`）
- 列表為可捲動單欄（工具變多時不壓縮列高；ScrollContainer 以 content min-size 驅動捲動）
- 增加資金（僅測試版，`ProductVersion.TEST_TOOLS`）
- 音效測試（僅測試版）
- 清除存檔並重新選擇劇本
5b. 小遊戲 hub（既有；條件見實作 `can_access_cultivation`）
- **釣魚太郎** `fishing_taro`（`theme_historic` 解鎖後；見 [`fishingtaro.md`](fishingtaro.md)）
- **魚缸欣賞** `fish_tank_gallery`（擁有 `fish_tank` 後）
6. 開始營運（主畫面底部強調按鈕，與難度列固定在內容區底部）
7. **開始營運（麻煩客人模式）**（僅測試版）：可選麻煩客人 LV1–6 或**混合 LV**；通過開店檢查後與一般「開始營運」相同確認流程。此模式進營運後**保證至少出現一名**麻煩客人（固定 LV 或混合抽 1–6）；正式版關閉或移除
8. **難度**（僅測試版，`ProductVersion.TEST_TOOLS`）：主畫面在「開始營運」上方、分類格下方固定，**簡易**／**普通**二選一。預設普通。選擇留在這次遊玩，不寫入存檔；正式版隱藏並一律當普通。按開始營運後，整段營運用這個選擇。正式三檔難度（簡易／普通／困難）、存檔欄與評價建議彈窗見 **`difficulty.md`**；與本測試鈕的合併方式於難度落地時處理。
- **普通**：維持現有劇本與技能規則
- **簡易**：
  - 一般客人抽出的清單上限不超過 5 件。該劇本原本更低（例如劇本 1 的 3）就維持較低的那個。麻煩客人仍以這次一般抽籤為基準再乘等級倍率。小偷清單不變。Yes! My Lord! 之後加貨仍可超過這個上限
  - 污物生成間隔 ×2（劇本 1 原本已 ×2 的，簡易再 ×2）。開場污物 1 團（普通為 2）。同時上限不變
  - 小偷出現判定 ×0.5，與霸王色疊乘。出現間隔仍按現有設計
  - 所有**增加**不滿的量 ×0.5（找不到貨、排隊、污物、衝刺、丟錯貨、麻煩客人趕客／煽動）。減少不滿（交付、安撫）不變。The World! 仍先改世界流速，簡易再把加上去的量減半

畫面上方狀態列（資金、LV、XP、三圍、點數、商店／支援評價）分兩行顯示，再加頁面說明一行，避免單行截斷。

按開始營運前先檢查店舖設計裡已經放好的物品。沒有通過就不能進入營運回合：
- 至少一台收銀機
- 至少一組同類型的補貨架和貨架（乾貨配乾貨、凍櫃配凍櫃，或冰櫃配冰櫃）
只購入、還沒放到店舖設計圖上，不算已設置。

按開始營運：通過檢查後扣當日工資，**寫入存檔**，再進入營運回合。營運完結並確定後返回營運準備頁。

#存檔與劇本

- 啟動時若有合法 `user://save.json`：略過劇本選擇，直接進準備 home  
- 無存檔：先選劇本。試玩起點含空店／中期／後期，以及 **劇本4「技能測試」**（LV10、三圍各 20、資金 $99999、規模 LV3 闊 18×長 10、商店物品各購入 2、已開發乾貨系＋倉庫各 200 件、店員補貨／收銀各 1、店面已放好可直接開工的左右配置；用來直接試技能，不用從空店買起）。**測試版**另有 **劇本5「教學模式」**（LV1、資金 $3000、空店；流量緩和同劇本1；見 `tutorial.md`）、**劇本6「頭目戰」**（內容藍本＝劇本4；選此劇本後「開始營運」進入頭目日，測 [`bosses/alien_tycoon.md`](bosses/alien_tycoon.md)；見 [`bossbattle.md`](bossbattle.md)）、**劇本7「新商店物品測試」**（藍本＝劇本4；普通收銀機收起，門口放 **一台自助收銀機** `self_cashier`；無收銀店員；見 `shopitem.md`／`cashiersystem.md`）、**劇本9「安桃山時代」**（熟食檔；見 `cookedfoodsystem.md`）、以及 **劇本10「精英店員營運日測試」**（安桃山 place shell；店鋪／已開發商品 bake 自活線存檔——米／醬油／零食＋凍／冰＋熟食檔＋魚缸；`elite_clerk_catalog` **全員 debug 解鎖滿級**；見 [`eliteclerk.md`](eliteclerk.md)）
- 系統工具可「清除存檔並重新選擇劇本」
- 系統工具可開關**虛擬搖桿**（`user://settings.cfg` → `[ui] virtual_stick`，**預設關**；僅 Web／手機且活躍輸入為觸控時顯示；手掣／鍵盤自動隱藏。營運暫停選單亦可改。見 `inputmodes-vj.md`）
- 系統工具可開關**背景音樂**與調聲量（`[audio] bgm_muted`／`bgm_volume`；與暫停選單共用。見 `bgm.md`、`pausemenu.md`）
- 系統工具可進入**語言選單**，從支援列表選取介面語言（`[ui] locale`：`zh_TW`／`en`／`zh_CN`／`ja`，預設 `zh_TW`；與暫停選單共用。見 `docs/alpha/i18n.md`、`pausemenu.md`）
