#技能設定
- 此檔案包含技能設定

#**技能COST**
COST 是一個數值。技能寫的「1 格」＝ COST 1，「2 格」＝ COST 2，「3 格」＝ COST 3。
越高級的技能 COST 越高。
營運回合裝備中的技能 **COST 總和不能大於 5**。
玩家能自由搭配不同 COST 的技能上場（總和 ≤ 5）。
奧義不佔 COST。

#**裝備技能**
準備回合有 **5 個具名插槽**（畫面／施放用，不是 5 條 COST 帶子）：
- 技能1（輕放技能鍵）
- 技能2（長按後上）
- 技能3（長按後右）
- 技能4（長按後下）
- 技能5（長按後左）

每個技能不論 COST 多少，都只放進 **其中一個** 插槽。2 COST、3 COST 的技能一樣可以放在技能 1–5 的任一格。
因為總 COST ≤ 5，用了 2／3 COST 技能時往往裝不滿 5 個插槽；空插槽沒有技能，選中不會發動。
被動技能也可以放在任一插槽：營運中自動生效，選單上名稱仍顯示但較暗，主動輸入無效。

#**施放技能操作**
技能鍵：鍵盤 L、Xbox／虛擬鈕 Y。
按下放開施放技能鍵, 會直接施放技能1
長按施放技能鍵後, 玩家角色頭頂會彈出技能選單
顯示方式:
上方:技能2
右方:技能3
下方:技能4
左方:技能5

玩家長按時再按方向按鍵上: 施放技能2
玩家長按時再按方向按鍵右: 施放技能3
玩家長按時再按方向按鍵下: 施放技能4
玩家長按時再按方向按鍵左: 施放技能5
長按施放技能鍵途中放手會取消輸入
施放技能鍵途中按方向鍵角色不會移動
速度類技能加成以該效果自己的 **%** 計算，不加減 AGI／INT（見 `playerstats.md`）。只加快移動的技能不會加快上架 Circle 或清潔計。

只有技能性質為主動技能才能施放
如果該技能插槽中的技能性質為被動技能, 指令輸入後不會觸發任何效果
被動技能在彈出的技能選單中會照樣顯示名稱, 但圖示會稍為暗淡表明為不能主動發動.

#**施放技能畫面效果**
施放技能時, 技能的名稱會有氣勢地彈出
施放時會有ZOOM IN到角色的Cut Scene效果

#**技能性質**
##主動技能
- 要放在裝備技能中主動使出

##被動技能
- 在店舖準備時準備, 店舖營運時自動生效

#**技能效果疊加**
- 補貨時段與營運時段都可以施放技能。
- CD 與技能持續時間在時停期間仍用**現實秒**（遊戲時鐘／客人動作可停，冷卻條繼續走）。
- **加速與加速**（主動或被動、玩家或客人）疊加，各 % 相乘，例如人肉數錢機與被動收銀速度。
- **客人已因技能完全停止**（如 The World! LV3）：不能再疊任何客人移動速度狀態；停止結束後，仍在持續的其他速度技能才生效。
- **客人同時被加速與減速**：不疊加。依**施放先後**，先發動的技能完整生效到結束，然後才輪到下一招改數值。
- 瞬間補貨 LV3 已略過上架 Circle 時，被動上架速度不改變結果（仍是瞬間）。LV1／LV2 的 Circle 倍率與被動上架 % 則疊加在 AGI 算出的時間之後。

#主動技能的技能冷卻時間
技能表上的秒數是 INT 10 的時間。
INT 越高 CD 回復越快：INT 50 為 150% 回復（實際 CD = 表列 / 1.5）。中間線性，見 `playerstats.md`。
主動技能施放後要等待冷卻時間經過才能再次使出

#**奥義技能**
角色在營運回合時能帶一招奥義技能出場
奥義技能不佔空技能COST
奥義技能要長按奧義鍵（鍵盤 U、Xbox／虛擬鈕 RB）然後輸入方向指令發動
長按後角色頭頂顯示指令箭頭（與收銀指令同一套圖示）.
依次序輸入, 如上上下下左右左右, 要完全正確才能發動技能.
放手奧義鍵會取消；任何一步錯誤則同一串從頭（該步顯示 X）.

#**施放奥義技能畫面效果**
施放奥義技能時, 技能的名稱會有更誇張有氣勢地彈出
施放時會有ZOOM IN到角色的Cut Scene效果

#奥義技能的技能冷卻時間
奧義表列 CD（例如 60 秒）同樣是 INT 10 的時間，受同一套 INT 回復倍率影響。
奥義技能施放後要等待冷卻時間經過才能再次使出
