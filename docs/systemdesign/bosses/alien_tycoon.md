# 頭目：外星大土豪（測試版）

- 工程 id：`alien_tycoon`
- 框架：[`../bossbattle.md`](../bossbattle.md)
- 測試進場：劇本6「頭目戰」（藍本劇本4）
- 外觀：活線复用體素 `player_alt1`（玩家·外星人）；正式可另換頭目專用 vox

# 設定

外星大土豪購物清單特長；完成一段後又想到要買更多，再開新清單。目標是**滿足所有購物清單並完成付款結算**。

# 目標

滿足全部清單段並完成三波付款 → 通關。

# 行為

- 仍計**上貨／交付時間**；頭目像一般客人進店
- **不主動購物**（同麻煩客人 `passive_shop`）：須玩家方向丟掉交付；NPC 店員不可代取
- **移動大幅加快**（約 2.5× 一般客人）；在店內多方漫遊（貨架／收銀台／通道／門口），頻繁換目標
- 跳過收銀的技能／店員代收／自助結帳對此頭目**無效**
- 購物清單隨機，限該店**可售**貨品（`sellable()`）
- 五段清單完成前**不前往付款**；購物車**累積**不清空
- 每完成一段清單：**不滿度清零** → 演出 → 開下一段
- 頭目日只留此頭目（無普通客／小偷／污物）；收銀店員不派出

# 階段表（進度條 8 格）

| 序 | 種類 | 內容 | 完成後 |
|----|------|------|--------|
| 1 | 清單 | 5 件 | 不滿歸零＋演出 → 段2 |
| 2 | 清單 | 8 件 | 同上 → 段3 |
| 3 | 清單 | 10 件 | 同上 → 段4 |
| 4 | 清單 | 15 件 | 同上 → 段5 |
| 5 | 清單 | 20 件 | 演出「去付款」→ 排隊 |
| 6 | 付款 | 5 指令 | 演出 → 波2 |
| 7 | 付款 | 6 指令 | 演出 → 波3 |
| 8 | 付款 | 10 指令 | 入帳 → 通關演出 |

- 進度 HUD：開場 8／8，每完成上表一列扣 1，通關 0／8
- 付款為**同一趟排隊**連打三波；波間插演出；**絕對指令數**（不套 INT 減次／預填／雙收）
- 三波全完才入帳；之後才加營業額／XP／資金（占位獎在結算）

# 時計與失敗

- 標準營運 3 分鐘（不夠再另調）
- 時計到點未通關 → 失敗演出 → 未付款貨退倉 → 回準備
- 不滿度滿 100 離店 → 同上
- 失敗不發頭目占位獎

# 演出流程

共同節奏：暫停時計 → ZOOM IN 頭目 →（可選一字標題／對話）→ 還原鏡頭 → RESUME。

## 補貨開場（上貨時間開始）

暫停遊戲時間 → 劇情框：「今天好像有事情發生⋯⋯還是專心工作。」→ RESUME（無 ZOOM）。

## 進店

1. 一字一字彈出：`外 星 大 土 豪`（一字一效果音）
2. 對話：外星大土豪：「好像很多東西要帶回羅茲威爾⋯⋯」

## 清單段完成後

| 剛完成 | 對話 |
|--------|------|
| 段1 | 好像還有什麼要帶回羅茲威爾⋯⋯ |
| 段2 | 想起了，還有更多的同伴在等我！ |
| 段3 | 還有更多⋯⋯還有更多⋯⋯還有更多！！！ |
| 段4 | 還有更多⋯⋯還有更多⋯⋯還有更多！！！ |
| 段5 | 終於買夠了，去付款吧。 |

## 付款波間

專檔測試版：波間可短暫停＋ZOOM（台詞可复用段間或靜默）；實作最小集允許僅 ZOOM／短停。

## 付款完成後

對話：好像買了很多東西⋯⋯回去吧。

## 結算前

大標題「任務完成」一字一字彈出，停約 3 秒 → 正常結算。

## 失敗

失敗演出（橫幅／短對話占位）→ 退未付款貨 → 回準備。
